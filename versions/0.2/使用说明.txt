补货助手 MVP 0.2.0 · Windows 64位试用版

一、启动
完整解压“补货助手_MVP_0.2.zip”，进入“补货助手”文件夹，双击“补货助手.exe”。
无需安装 Python 或 Excel；本地离线计算。
请保留旁边的 _internal 文件夹，不能只把 exe 单独拿走。

二、第一次试用
1. 在左侧选择或拖入“补货建议导出服务.xlsx”。
2. 在右侧选择或拖入“混合仓商品资料.xlsx”。不需要模型1参考主表。
3. 自动读取完成后核对门店、匹配数量和地采数量。
4. 核对分仓参数。此版沿用本批已验证基准：河北仓备货8天、到货4天；山东仓备货8天、到货5天。未知仓必须自行填写。
5. 保持“启用一箱例外”勾选，点击“计算并筛选”。
6. 默认按执行金额从高到低显示建议补货商品，已排除商品资料禁用、补货建议停采。可切换“已排除”“商品资料禁用”“补货建议停采”“全部商品”、地采、待处理、一箱例外等范围，按仓/分类筛选，搜索商品名称、编码、条码。
7. 点击商品行，右侧查看销量库存、价格箱规、需求预测、额度与补货原因。
8. “导出补货清单与明细”导出整个门店本次结果；“导出当前筛选”只导出当前可见范围。两种导出均单列“补货清单”和“已排除”；补货清单不包含禁用/停采商品。保存时需要新文件名，不覆盖已有文件。

三、这版的业务口径
• 商品资料状态=禁用，或补货建议状态=停采，任一命中即默认不补；同时命中也只排除一次。状态筛选在原计算之后执行，不改变预测、库存额度、资金约束等计算。
• 区分“计算建议/计算金额”和“执行补货/执行金额”：已排除商品计算结果保留供分析，执行数量和执行金额为0。默认界面、顶部金额、补货清单使用执行口径。可在“已排除”或“全部商品”查看计算参考，不提供放行禁用/停采商品的操作。
• 原计算核心保持不变；未统一两套日均，未套用安全余量2/3/4天试验。
• 一箱例外只在原计算完成后执行。只有资料精确匹配、数据有效、导出补货状态正常、中心仓启用、有真实销量、箱规大于1、原建议为0、可用及在途撑不到到货、且确因库存额度或资金约束拦截时，才放行一箱。
• 非例外商品的计算数量与金额保持原模型结果。原模型已有建议也不会额外加箱。关闭例外开关并重新计算，可查看原模型计算结果；禁用/停采筛选仍生效。
• 缺失箱规按已确认规则补1；分类未配置时使用“无分类”的快销权重。基本售价作为金额单价。
• 销量、可用库存、在途、补货数量均按库存单位，不另做采购单位换算。
• 商品资料未匹配的标记“地采商品”。保留其销量、库存、原始行位置，本版不生成地采补货数量及金额，不把缺失价格当成0。
• 商品资料重复、商品编码异常仍进入“待处理”，避免把无法确定的匹配关系当成正常地采。
• 顶部金额为本次全店默认补货金额，已剔除禁用/停采，仍包含未排除商品的原模型极端恢复。表格上方分别显示当前筛选范围的执行金额、计算金额、排除及异常数量。

四、结果有效性
更换文件、门店或修改参数后，需要重新计算；旧结果不能直接导出。
运行中可取消。数据错误会显示原因；有效商品可以继续计算，待核商品保留待核状态。
输入工作簿只读；结果写到用户选择的新文件，原模型和源Excel不覆盖。
导出含概览、补货清单、明细、已排除、地采、待处理、一箱例外、参数，保留输入文件SHA256及源行，便于核对。
本版不支持人工修改补货建议数量，不自动下单。

计算参考金额：原模型23,454.75元；启用例外后23,833.55元，原计算值全行保留。
禁用1,973行，停采1,564行，重叠268行；合计排除3,269行，其中616行原有正计算建议，剔除计算金额11,564.68元。

8个一箱例外仍保留，新增378.80元；未命中禁用/停采的10,975行执行数量金额与上一版一致。
已核验原文件校验值、例外边界、界面导入计算筛选、参数失效、Excel导出以及打包后的程序运行。
验证环境为当前Windows 11电脑，尚未在其他电脑实测。

六、问题定位
错误提示会说明原因。界面日志位于用户目录AppData\Local\YoutuanTools\补货助手\app.log。
本版是最小试用版；其余完整模型参数可在“查看完整模型参数”中查看，首版只读。
软件使用Python、Qt/PySide6、openpyxl等组件，第三方许可随包附在 licenses 中。

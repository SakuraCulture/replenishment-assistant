# 补货助手 0.50.1 rc3：付款只按商品编码认单

交付日期：2026-11-10。分支 `fix/payment-sku-only-0.50.1`，本地交付，未推送、未合并。

## 改动

按用户确认的业务口径，移除聚水潭财务／付款单的辅助码与签发条码匹配。商品编码准确时，不再因为辅助码指向另一商品或多个商品而拦截；商品编码未知时，也不允许通过辅助码把它改成另一商品。

- `order_lifecycle.match_payment_rows`：去掉辅助码冲突判断、条码索引及辅助码回退改写商品编码。仍按商品编码检查所选仓单与跨仓归属。
- `lifecycle_io.payment_specs`：辅助码为可忽略原表字段，缺列或同名辅助码列不阻止读取；关键字段的重复表头校验保留。
- 原始文件与原表字段继续留存，无需用户手工删除辅助码列。已保存的历史付款不自动改写。
- 门店、签发修订、内部订单号原关联、重复绑定、数量及金额差异核对继续保留。补货模型、预算、箱规、归属规则与存储格式不变。
- 随包使用说明、离线 HTML 手册及《0.50.1付款按商品编码认单》同步更新。

# 0.33.0 重点试用

打开独立目录 `交付_0.33.0_rc1/补货助手/补货助手.exe`，保留整个文件夹。旧版安装包保留；不要同时用0.32.2与0.33.0对同一资料库继续分配，旧版不认识新批次库存边界。需要退回旧版继续作业，应使用升级前备份，不在新增批次库上混用旧分配入口。

1. **入口范围**：订单跟踪筛选日期、门店和河北仓，进入聚水潭导入单；应保留范围。勾选单进入时只看所选单。页面加载完成后进度条消失，不表示订单业务已完成。
2. **新批分配**：选择两家已回传门店，准备新批次，为仓选资料，预览后确认。检查门店顺序、满足金额及削减SKU；可导出后直接导出，不必重新分配。
3. **暂停和继续**：生成过程中停止，关闭页面再选原批继续。已有单保留，只处理未完成单；原批资料不能在中途替换。
4. **下一批**：其他订单选择另一份库存开始新批，应直接从这份库存分配，不再扣前批。资料是否已反映平台实际占用由业务决定。
5. **筛选导出**：搜索一店，按钮份数随筛选变化，只导出可见范围；清空搜索后恢复全范围。重复导出不会重新分配或扣库存。
6. **撤销/重分配**：在其他订单操作中撤销未使用生成单，确认不再自动出现；选择原批勾选未锁单重分配，未选单不变。未完成任务有独立撤销入口，已生成、已锁及已有付款/收货保护仍在。

这轮未做真实平台下单，也没有改变翱象或聚水潭浏览器连接。首页待办、固定表格列等下一阶段UX建议尚未实施。

# 0.23.0 rc1 聚水潭导入单导出简化

已完成实现、独立对照、回归及实际EXE验收。正常操作为：进入“聚水潭导入单”→查看门店汇总→点击“导出本批全部”或“导出勾选”。再次导出仍在本页点击同一按钮，无需重算、切换全流程或进入额外已生成列表。

## 使用与交付

- EXE：`交付_0.23.0_rc1/补货助手/补货助手.exe`；使用整个文件夹。
- 完整ZIP：`交付_0.23.0_rc1/补货助手_0.23.0_rc1.zip`，48,619,744字节。
- 操作说明：`docs/0.23.0聚水潭结果与导出.md`，同时已放入试用包的使用说明.txt。
- 已导出、已锁、已付款和已收货不移走有效结果；搜索不缩小整批导出；后台后续生成不被结果页挡住。普通导出仅取当前有效结果，零分配显示但不生成空文件。
- 每店每仓一文件，四列、数量、单价、订单号、文件名、商品行和生成顺序保持。
- 导出后同名覆盖；文件占用有门店/仓和错误提示；取消、失败可以按原生成记录重试。资料/回传变化显式待核，重算和确认保存仍在独立入口；旧结果可明确确认导出。

固定基线为0.22.1：`63a1b18ee22693c21cbf1024198e43025df652e3`。

应用0.23.0；模型0.3.3-rules、仓归属0.5.1、物理存储2、参数及作业逻辑schema1保持。10个新增/变化src文件限于结果查询和界面、入口、自动任务界面协调、验收入口及应用版本；另外137个src文件逐字节哈希相同。模型、预算、一箱例外、商品归属、JST分配/生成/库存/任务/导出实现和默认业务配置均未改。完整清单在source-differences.json与source-hashes.json。

## 性能与限制

新结果页31店62仓单合成样本，单机串行3轮，同环境和输入；冷指新缓存首次查询，未清操作系统文件缓存。计时含摘要生成及缓存写入，暖查询含校验和汇总；不含进程启动或Qt渲染，不冒充端到端耗时。

|查询|3次原始秒数|中位数|最小～最大|
|---|---|---|---|
|新缓存首查|0.513603、0.498488、0.526778|0.514秒|0.498～0.527秒|
|复用缓存|0.074784、0.070271、0.077649|0.075秒|0.070～0.078秒|

新结果页实际EXE两次运行的最大Qt心跳间隔0.111秒；每50ms采样主进程加子进程RSS之和峰值278.39MiB，共享页未去重；包含整段自动操作，不是单次导出净耗时。六次EXE中原高级生成流程最大心跳0.296秒、最高RSS312.70MiB。以上是本机小合成样本，不代表大规模真实门店、其他机器或冷文件缓存性能，也没有以旧UI作同规模性能对照，不宣称“导出快了若干倍”。

本轮未重新执行30组真实模型回归；用未改核心文件哈希、363项适用回归及冻结导出对照证明本次范围，未把旧报告算作新结果。没有重新验收远端聚水潭导入或多机共享库存。未测试所有屏幕尺寸/缩放组合。业务首次历史索引仍有原成本，后台查询提供阶段进度。

# 补货助手0.52.0 rc2交付报告

## 结果与业务用法

新增运营签发：门店回传 → 运营签发 → 聚水潭分配 → 付款 → 收货。运营与回传共用模板、导入核对及保存规则，独立留存版本，不增加运营审批。支持单张/批量导入导出、一键采用回传及“分配并准备付款”；付款仍须明确核对并保存，不会自动向平台下单。旧订单沿原流程继续，历史回传、付款和分配不被升级重写。

经营分析新增七节点事实、日/周/月趋势、多维筛选、周期下钻及简洁经营导出。原五段定义保留，数量、款数、货值分开；单号后置。独立缺货率需主动联看既有日报，不自动联网、不更新补货资料。图文手册同步到0.52.0，23章、104页、52张图。

截图中非整箱需求被整行置0的代码缺陷已复现：旧分配器在需求不能被箱规整除时直接报“回传数量不符合箱规倍数”。本版先向下规整需求，再分配本批余量，库存不足不再次整箱取整。保留原需求、规整余数、分配前后库存、缺口及原因。

默认资料、全局分配基准、原批冻结库存属于不同对象。保留现有选择顺序及冻结占用；默认资料与当前基准版本不同时增加提示，不擅自刷新旧批。真实业务机11月12日采用的库存原件尚未取得；本机只读元数据最新11月8日，不能据此断言业务机资料更新正确。

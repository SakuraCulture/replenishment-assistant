# 0.48.2 rc1：配置窗口关闭与全局配置回显

2026-11-08 本地独立交付。分支 `fix/setup-close-0.48.2`，构建源码 `b3b1636d9ae0eb353b0a4e00f6657ccb8b078f05`，基于 `v0.48.1-rc1`。未推送、未合并；没有关闭用户当前应用，没有改写现有连接配置或真实业务数据。

## 原因与改动

用户反馈配置窗口的 Edge 和用户配置为空，且不操作直接关闭后连接失效。确认了两处代码问题：

1. 窗口初始化只读取门店目录，没有回显已保存浏览器、用户配置、门店绑定和共享登录状态，“尚未连接”是默认文字。
2. 主窗口在配置窗口返回后无条件调用一次登录重查，无论用户是否操作。这会再次访问页面，失败时改变全局状态。

本轮对旧版和新版实际入口回调做了隔离对照：同样只打开并返回，0.48.1 触发登录重查 1 次，0.48.2 为 0 次，见 `close-entry-comparison.json`。未发现直接关闭会删除磁盘绑定的代码路径，不能据此声称用户绑定曾被清空；真实浏览器当时具体失败原因仍无现场复现证据。

修复取消“关闭即重查”；窗口只读共享组件的已保存表单字段和连接状态。已保存门店恢复核验标识，未核验门店仍明确显示未核验。关闭仅释放本窗口操作权，进入补货建议继续复用同一连接。手动检测浏览器时精确选择原绑定；原路径找不到时不自动替换成列表第一项。首次配置、新增/变更门店、显式核验与保存、底部连接修复继续保留。

配置接口只增加 Edge 路径/版本、用户配置路径/目录和下载目录的白名单字段；不返回整个机器绑定对象。未增加导出、采购、重试或跳过身份验证。模型、默认参数、仓归属、删除与缺货率指标口径不变。

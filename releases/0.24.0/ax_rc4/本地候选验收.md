# 0.24.0 ax_rc4 核验异常与采集流水线

## 问题与修改

1. 原核验仅在部分连接错误时结束，身份/页面超时和未知错误可能逐门店重复等待；只读取消等当前查询自然返回。现在只允许明确门店名称/编码错误继续其他店，其他异常结束；每一步有上限、错误码和退出状态，只读取消释放执行器。配置未确认不写入。
2. 原Qt状态请求失败后定时轮询仍可能重复触发。现在停轮询、只报一次、禁用保存，提供“异常后重新连接”；旧只读执行器退出后才能重试。浏览器检测不再显示核验100%。
3. 原MachineRuntime每店等Coordinator下载完才轮下一店。现在先依序查询/提交，平台生成重叠；随后轮询各精确任务、处理已完成文件，慢首店不挡后店。提交和网页交互互斥，下载逐文件；没有多浏览器乱序操作。结果、采用文件和门店列表保持原顺序。
4. 任务号、范围、受理不明防重、原文件核验、发布/冻结规则不变。新增item.phase、item.task_id为过程状态；模型结果没有新增或忽略业务字段。只读核验取消不改变采购上传的不可重放边界。

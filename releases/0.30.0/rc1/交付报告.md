# 0.30.0 rc1 生命周期对比交付记录

订单跟踪新增“导出订单级对比”“导出门店级对比”，支持勾选订单或当前筛选全部，跨页无需逐页全选。统一用签发时基本售价比较各环节货值，源单实际付款金额另列。门店报表附分仓、订单和差异商品，原商品级对照入口保留。

- 固定基线：`f36389abd18a5d8360dfa20a381a5adc28879b4f`，0.29.0。
- 独立分支：`feat/lifecycle-comparison-0.30.0`。
- 干净构建提交：`ff89b8af18eeff358153f83a443f56b944843d82`。
- 应用0.30.0；模型0.3.4-rules、参数schema3、仓归属0.5.1、存储格式2保持。
- 本地标签 `v0.30.0-rc1` 指向含本记录的证据提交；与构建提交分别记录。未推送、未合并。

## 可使用的输出

订单报表：订单级对比、差异商品明细、实际付款金额、统计口径。门店报表在此基础上增加门店级对比、门店分仓对比。每订单/门店列各环节商品款数、按签发价已计价货值、相邻环节差额、实际付款。不同库存单位不混加总数量，逐商品数量保留在差异明细与原商品级导出。

未导入、旧资料不完整、上游更正后待重新核对、无需后续环节不当作0；确认0仍是0。门店阶段合计列有效订单数，差额列可比订单数，避免把缺回传的订单统计成减少要货。缺签发价不填当前价，多币种实际付款不混加。旧修订选择已过期时要求刷新，不改写原签发或生命周期。

完整口径、操作及复跑命令见 [0.30.0生命周期对比](../../../docs/0.30.0生命周期对比.md)。

## 交付与限制

运行 `交付_0.30.0_rc1/补货助手/补货助手.exe`；完整ZIP为同目录 `补货助手_0.30.0_rc1_生命周期对比.zip`，需保留整个文件夹。0.29.0保持。先保存并关闭旧程序再打开新包，避免并行占用日常配置。

建议试用：在订单跟踪先筛一个门店，导出门店级对比；核对“有效订单数”和“可比订单数”，再到订单/差异商品表查看减少发生于哪个环节。再筛全部门店导出订单级报表，确认金额按签发价，实际付款金额单列。

大范围差异仍需保存投影列表，尚未测量长期海量历史的峰值内存和耗时；Excel压缩阶段取消需等当前安全阶段结束。全筛选导出按原条件重新读取，数量变化要求刷新，同数量集合变化以导出时结果为准。旧历史缺价/缺数量只提示，不补造资料。

本轮只使用隔离QA，未写日常用户配置或订单，没有对运行中的日常库作静态哈希承诺。未重新验收跨机安装、全新机器构建或真实翱象平台，不把本轮本地EXE通过扩张为这些结论。

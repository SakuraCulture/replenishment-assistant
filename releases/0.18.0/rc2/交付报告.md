## 如何试用

计算完成 → **最终清单 / 改量** → 选店 → 直接改数量或**按清单补足** → **核对修改与预算** → 确认列出的风险 → **应用最终数量** → 原有**确认签发并导出**。

箱规24只能0/24/48……。原自动安排只读；人工0须原因及双零缺货风险确认；超当时库存额度须逐项确认。两仓共用整店预算，0预算不补，超支只允许有明确来源的一个末尾出库单位且≤5%。不自动改动其他商品、不自动再分配释放的资金。

清单可用于新品、活动、计划；有货即可或补足目标，库存状态可选。拖拽导入、最低模板、字段映射、版本复用和原Excel留存已接通。缺数据/地采/禁用/停采/缺价等不会被铺货绕过，未应用明细可查看/导出。待核对草稿可保存，但不能签发。历史可选“签发前调整”逐商品复查；生命周期推荐数使用最终签发量。

未改量结果基本持平，不宣称提速。人工改量增加来源、风险、数量和金额的严格复核成本；本组总链比新版未改量增加约6.49秒，包含1.34秒预览。主进程加子进程工作集每20ms采样，共享页可能重复计入，OS文件缓存未控制；不能外推多店/冷盘耗时。性能样本采自最终关注值识别补充之前的代码，该补充只作用新增清单导入，不在上述性能链路内。

# 0.53.1 rc1 分配实际采用仓资料导出

新增“导出本批采用仓资料”：同一Excel核对资料批次、实际采用字段和分配前后库存。只读导出，不采集、不更新、不重分配、不占库存。

## 使用

- “准备新分配批次”：选资料并预览后，点“导出本批采用仓资料”；标明“未确认预览”。
- 原批窗口：直接导出原批冻结资料，不要求先重算。
- “聚水潭导入单”结果页：批次视图导出该批，日期视图优先按勾选仓单导出，否则按当前筛选内已保存生成单导出。按钮明确范围/数量。

导出三类表：“资料批次”“采用字段_仓名_序号”“分配核对”。业务资料在前，批次/库存依据等关联号保留。不同依据分表；原批重分配只列当前生效生成单，显式历史记录注明历史状态。

## 正确性和保护

实际采用的bid定位原jst_baselines，验证摘要和仓/资料版本；不读取当前默认库存替代。缺原依据、坏摘要均失败。平台导出时间未可靠留存时写“未留存”，不冒充平台最新库存。

采用字段不是原Excel全部列，完整原件继续用“查看当时资料依据 → 下载当时仓商品资料原表”。资料版本相同不能证明没刷新。

释放数据库读事务后再写Excel；Excel写入期间不长期持有数据库读事务。取消不发布半成品，已有文件不覆盖，编码及公式样式文字保留为文本。导出不写业务表、不改变原记录。

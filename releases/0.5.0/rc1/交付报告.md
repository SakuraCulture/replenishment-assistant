# 补货助手 0.5.0 交付报告

已完成分仓资料维护与门店主从仓需求归属。主仓禁用、无货或无该商品时归属从仓；从仓无货仍保留需求，不增加“仓库暂不可供”排除类别，不拆单、不按仓库存限制需求、不预占库存。禁用/停采、最低持有、一箱例外及必卖优先总预算仍沿用原规则。

## 试用

- 启动：`交付_0.5.0_rc1/补货助手/补货助手.exe`。
- 迁移到其他目录或电脑：完整解压`交付_0.5.0_rc1/补货助手_0.5.0_rc1.zip`，不要单独移动EXE。
- 先在河北仓、山东仓各自入口导入对应商品资料，再添加补货建议、检查文件。按店选主仓/从仓，单仓选择“无从仓”，设置预算后计算。资料与门店设置跨批次复用；仓可用数是导入时快照，变化后须重新导入。
- 选中仓的基本售价、箱规、状态、分类权重和仓到货参数参与计算。两仓需求共用本店一个预算。修改单店主从仓只让该店待重算；更新共用仓资料需重新检查并重算本批数据。
- 导出新增“分仓需求汇总”和主从仓、归属说明、库存快照判断及来源版本。已有混合资料可选择兼容0.4模式。
- 交互图、字段对应与边界规则：`docs/0.5.0分仓需求归属.md`；完整操作说明随包提供。

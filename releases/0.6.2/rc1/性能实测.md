# 多文件检查性能实测

New interpreter per run; AB/BA/AB alternating, one run at a time. 50 ms Win32 process-tree WorkingSetSize (RSS) and PrivateUsage samples during bs.load only, including parent and all descendants; RSS sums count shared pages more than once. Misses peaks between samples. Controller excluded. Intake includes master snapshot, file hashes/checking and ordered cross-file merge/dedup. Prepare is subsequent matching/normalization; total measures load call including pool start, IPC, shutdown. OS cache not cleared; repeated warm/mixed-cache timings, not cold disk benchmarks. No concurrent benchmark work. File partitions/excerpts are synthetic layouts of actual rows; mixed uses a same-writer synthetic re-encoding of the full real rows plus three exactly identical 100-row excerpts.

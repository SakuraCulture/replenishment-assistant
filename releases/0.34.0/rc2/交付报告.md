## 兼容与边界

- SQLite 只在明确保存时新增全局映射及事件表；模型配置字典、原每日作业存储及历史签发格式不迁移。
- 历史参数及映射快照不回写；新默认不偷偷修改当前作业。当前实际参数改变后结果失效，需要重算。
- 旧预案缺少字段选择信息，仍兼容其原有整套选择；新日常预案使用勾选字段。旧方案库保留兼容入口。
- 本轮没有注入或迁移用户正式配置，没有真实平台取数/采购联调，没有修改翱象或聚水潭组件。参数维护操作的 UI 心跳仅用于小样本响应验收，不作为大批量性能基准。
- README 及项目进度文档属于并行的文档整理，未覆盖或纳入本次提交。首次保护比较发现 README 被该作业更新，已在报告 external_document_changes 单列前后哈希；未扩大任何业务字段忽略范围。
- rc1 在复查时发现继承值只显示“沿用门店”不直观，因此补充实际值显示与专项测试后重建 rc2；rc1 保留但不作为最终推荐包。

## 复跑

在项目根目录，用已安装依赖的 `.venv\Scripts\python.exe`：

```powershell
$env:PYTHONUTF8='1'
$env:QT_QPA_PLATFORM='offscreen'
.venv\Scripts\python.exe -m unittest discover -s tests -v
.venv\Scripts\python.exe -m unittest discover -s tests -p test_parameter_workspaces.py -v
.venv\Scripts\python.exe tools/verify_parameter_workspaces.py freeze --qa qa/parameter-rerun-unique
.venv\Scripts\python.exe tools/verify_parameter_workspaces.py before --qa qa/parameter-rerun-unique
.venv\Scripts\python.exe tools/verify_parameter_workspaces.py after --qa qa/parameter-rerun-unique
.venv\Scripts\python.exe tools/verify_parameter_workspaces.py compare --qa qa/parameter-rerun-unique
.venv\Scripts\python.exe tools/run_parameter_workspace_ui.py --exe '交付_0.34.0_rc2/补货助手/补货助手.exe' --out qa/parameter-exe-rerun-unique
```

QA 输出目录必须新建；以上脚本设置独立用户目录，不读取日常设置执行测试。固定输入来源为仓库本机已有 qa/governance_032/inputs，业务输入不纳入 Git；搬到其他电脑复跑独立大样本对照时需复制该冻结 QA 数据集。单元测试与合成 EXE 验收自带所需夹具。

完成必要验证后停止本轮开发。后续若增加其他参数组、迁移旧店映射，应按明确选择进行，不改变本版默认值或业务规则。

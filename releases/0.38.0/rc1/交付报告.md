# 0.38.0 rc1：AI / CLI 查询与试算更新

已完成并独立打包。用户授权范围是查询与试算，定时任务只读；没有开放 AI 启动平台取数、定时调度或采购。保留 0.37.0 rc1/rc2，未替换正在使用的版本，未修改正式客户端配置。本轮仅本地提交与标签，没有推送或合并。

## 版本与实现

- 基线：`ecdc9e197d1c748eae1c78fb434fda4a7a77a9e5`。
- 开发分支：`feat/ai-cli-refresh-0.38.0`。
- 干净构建提交：`4d02bfbf5cf852d702caab7f55cd9921f8c892c7`；主程序和 AI 接口来自同一 Git 归档。
- 发行证据提交由本地标签 `v0.38.0-rc1` 指向；标签提交仅补充本报告和验收记录。
- 应用 0.38.0；模型 0.3.4-rules、归属 0.5.1、参数格式3、作业格式1、存储格式2均不变。

MCP 握手不再固定返回0.35.0。配套接口新增 `version / tools / doctor / call` 四类 CLI 用法，沿用本机 QLocalSocket 和工具校验，旧的 `--connection <路径>` MCP stdio 启动方式继续可用。连接无效、断开、版本不兼容或业务拒绝有结构化结果；不回显连接密钥，不自动开连接或修改客户端配置。

参数核对区分 current（本次）、defaults（已保存默认）和 preview（指定试算冻结值），保留原值、继承后实际值、中文分组、快照签名及全局映射。方案名只代表快照标识，未伪造逐字段编辑历史。准备任务只增加轻量签名；详细参数按指定门店查询，避免把全部参数堆进进度响应。

文件查询区分登记与本次检查报告；输入改变后不把旧报告当作可用依据。定时查询使用原服务的元数据、门店页及事件游标，不读整批商品大块快照，不调用启动、恢复、暂停或采集服务。AI 新计算在定时计算或结果采用运行时返回 BUSY。新增「查看定时补货进度」内置场景，共十个场景；连接配置导出同时附带本机可复制的 CLI 用法。

## 边界和未验证内容

本轮没有启动真实平台导出、修改定时安排或自动重跑业务任务。未重新核验 WorkBuddy 的正式连接，未改动 Codex / WorkBuddy 的现有配置；以前连接不可用的问题不能据此宣称在该客户端已解决，需使用新的配套接口路径启用连接后诊断。本轮未运行自然语言模型，十个场景工具链重放不等同于十条提示词在各模型上的成功率验证。没有全新电脑或逐字节可复现构建验证。

只允许变化的内容是接口版本信息、查询与试算预览的展示字段、新增只读工具、CLI及帮助文本，以及AI任务与定时执行的互斥提示。计算、资金分配、归档数据和导出业务结果未变。

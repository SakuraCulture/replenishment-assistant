# 补货助手 0.6.0 交付报告

已实现每日作业保存、门店完整默认配置和可复用参数方案。按中国标准时间每天保留一份整批作业；同日覆盖必须确认，默认取消。旧模型、原始Excel、旧版交付包和日常用户配置均保留。

## 直接试用

- 程序：`交付_0.6.0_rc2/补货助手/补货助手.exe`。
- 完整压缩包：`交付_0.6.0_rc2/补货助手_0.6.0_rc2.zip`。需完整解压，保留旁边的_internal目录。
- 第一次按“准备数据 → 门店与参数 → 计算进度 → 查看与导出”使用；保存作业在顶部。
- 标准补货v1已配置原模型参数、快销/日百权重、分类映射、河北8+4/山东8+5天和一箱例外。新店预算、主从仓依实际业务选择；不会替门店猜资金或仓库归属。

## 三种保存分别做什么

| 操作 | 保存内容 | 下次效果 |
|---|---|---|
| 保存作业 | 当前整批输入、仓资料、必卖清单、各店生效参数、结果和状态；含未完成门店 | 每日一条，今日可继续，历史只读；不自动修改门店默认 |
| 保存为本店默认 / 保存所选门店为默认配置 | 完整模型参数、仓周期、一箱例外、预算、主从仓等 | 同一门店下批及重启后复用；不自动替换每日作业 |
| 复制另存方案 / 保存方案新版本 | 完整通用参数方案，名称和不可变版本 | 可跨店选用；旧门店与作业继续保留原版本快照 |

“仅用于本次”保留本次修改，需要永久复用再明确保存默认或方案。计算完成不会自动覆盖作业。关闭或新建时有未保存变更会询问。

同日覆盖弹窗展示原/新保存时间、门店范围、有效完成金额、减少门店和完成变失效门店；详情列出数据版本与设置差异。取消不丢当前结果、不改旧记录。保存采用数据库事务；写入失败保留旧记录，另一窗口已先保存时拒绝过期确认。

跨午夜保存时选择原作业日期或今日；目标日已有记录仍需确认。历史记录可导出、复制配置用于今日；复制不带旧销量库存，需重新导入今天数据。

## 参数与恢复

界面列出15项模型参数及中文作用、单位、调整方向；通用备货/到货值在各仓周期页维护，固定极端边界仅展示。另可维护预测权重、分类映射、仓周期和一箱例外。w3自动计算，无分类跟随快销。调整前可同快照试算金额、缺口、变化商品和分箱规持有天数分布；试算不改正式结果。

标准方案直接沿用原规则，没有加入3.5+5天、统一日均或安全余量天数上限试验。自定义参数方案的业务效果不自动视为最优或已业务验收。

已检查的输入、商品资料及必卖清单保存为快照；原Excel移动后可恢复、重算及导出。未检查的文件只保存引用，仍需原文件。打开记录不自动套用当前仓资料；明确选择“使用当前资料重新检查”才刷新且使结果过期。

数据保存在本机AppData/Local/YoutuanTools/补货助手/settings/workbench.sqlite3。升级不覆盖。迁移作业和方案需先关闭全部补货助手窗口，再完整复制settings目录。当前没有云同步或自动下单。

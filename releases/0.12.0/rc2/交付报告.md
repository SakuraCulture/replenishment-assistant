# 0.12.0 rc2 交付与验收

已完成历史跨批次多选、三个独立导出入口、按单分别/按仓合并、原Excel原件下载及明确的加工资料核对表。保留0.11.0和其他旧包。本轮仅本地提交与打包，不合并、不推送。

## 使用入口

运行 `交付_0.12.0_rc2/补货助手/补货助手.exe`，完整压缩包为同目录 `补货助手_0.12.0_rc2.zip`。必须保留整个程序目录，不能只拷贝EXE。

历史归档页：筛选日期/门店/仓 → 勾选仓单 → 点击“导出完整计算表”“下载商品资料原表”或“导出签发建议” → 选择文件组织方式 → 核对修订与范围 → 选择目录。翻页保留选择，查询变化清空选择。每次导出自动新建任务目录。

- 分别模式：每个日期、门店、仓库、修订一个Excel。
- 合并模式：同仓多订单纵向追加到一张工作表，山东河北仍分文件。相同SKU不跨单相加，保留各自参数、价格、箱规和数量。
- 原件：原文件字节直接复制，可同仓同SHA去重，关联订单写在预览及导出清单；全部工作表、样式和公式保留。
- 加工核对表：只含订单相关商品的精确源行，名称明确标“加工表”，不能当原表。
- 缺失/校验失败单据明确列出，部分导出需显式勾选。每仓合并文件不发布半份内容。取消后已完成文件保留，失败/未执行项可按原修订重试。

## 耗时与限制

真实输入两组场景的单次测量（包含预览准备）：计算表分别约64.12秒、合并65.19秒；签发表分别13.82秒、合并13.75秒。核对准备各约5.8至6.4秒。旧版四份三表一起导出约55.46秒，但内容和流程不同，不能作为严格提速比较。本次没有宣称完整计算表提速；完整计算表包含数百万参数/过程单元格，仍然较慢。

文件导出串行。快照解码、单原件读取及Excel压缩保存期间，取消需等待当前安全步骤。首次历史查询会重建派生索引，大库仍有冷加载成本。历史原件未留存时无法自动还原，绝不拿当前同名文件或字段说明补造。超Excel容量时拒绝并提示缩小范围，不自动截断。未验证全新电脑逐字节可复现构建。

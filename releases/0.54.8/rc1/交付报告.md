# 补货助手0.54.8 rc1：轻量性能日志

默认开启，业务无需单独打开监控。遇到慢或异常后，尽快使用“显示与帮助 → 轻量性能日志（近24小时）… → 导出近24小时性能日志”，把生成的ZIP发给排查人员。正常关闭旧版后解压完整新包运行；未自动替换现用程序。

## 记录内容与边界

每5秒采样一次主程序和至多16个直接持有的Python/组件作业进程；1秒界面心跳只更新内存中的时间，不写磁盘。包括CPU时间与核心占用、私有提交、驻留、逻辑I/O、系统可用内存和提交额度、界面心跳延迟。保存、签发导出、回传等通用后台操作和翱象/聚水潭组件请求记录总耗时；进度映射为固定阶段和数字进度，不保留原文。

日志保存在本机控制目录下的diagnostics/performance，与可搬迁业务资料目录分离。原始日志合计最多16MiB，定期清理24小时前的文件；高频作业达到上限会提前轮换最旧记录。导出严格筛选近24小时内容。队列最多256条、活动操作最多32个；日志自身CPU时间、写入字节、丢弃和错误计数也会保留。

后台批量写盘，不做逐商品写盘、不fsync、不扫描全机进程、不收集堆/调用栈。磁盘不可写、计数器失败或队列满时丢弃诊断记录，不阻断业务。显式导出时尝试后台刷新刚完成的操作，最多等2秒；失败仍可导出已有记录，摘要标明不完整。退出时停止日志，不创建Qt窗口或改变实例保护。

ZIP仅包含说明.txt、环境.json、性能日志.jsonl、摘要.json。字段白名单排除商品、门店、金额、单号、文件路径、SQL、参数、请求响应、Cookie、账户和原始异常文字；不包含app.log、业务库或浏览器资料。

5秒采样可能漏掉短峰值，短操作仍记录总耗时。CPU cores=1表示用满一个逻辑核心。私有提交不是物理内存；进程驻留相加可能重复统计共享页。逻辑I/O包含管道，不等于物理磁盘吞吐或等待。系统休眠、时钟及调度也可能影响心跳和时间记录；不能单凭一个指标认定根因。未监控外部Edge及组件内部未直接持有的后代进程。并发/嵌套阶段不可相加当作总耗时。崩溃或断电可能丢失最后约5秒未落盘记录。精简环境信息是导出时的应用版本。

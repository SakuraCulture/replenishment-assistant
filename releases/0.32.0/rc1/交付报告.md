## 实际 EXE 验收

`exe-report.json` 明确记录 `frozen_exe=true`，版本及构建提交与交付一致。实际 Windows Qt 窗口及 spawn 子进程完成：

1. 拖拽参数 Excel、后台读取、预览取消、仅本次应用。
2. 计划编辑保存、明确替换预览、采用和重查，双店预设保留。
3. 两店并行计算；资质/拒收维护后仅受影响店失效并重算，原建议保留、拒收执行归零。
4. 通过实际进度对话框和子进程保存草稿、恢复、原子签发。
5. 分仓签发导出、隐藏关联信息、批量回传完整差异核对、取消及确认保存。
6. 缺少隐藏信息的文件必须明确选择目标单，取消不改变已保存回传。

小型合成双店走查的 25ms 心跳共 117 次，最大间隔 **0.25 秒**，包括同步夹具和截图阶段。截图在 `qa/governance_032/exe-rc1/`。这证明覆盖路径可执行，不代表大批量界面性能或业务人员无提示的独立易用性验收。

# 聚水潭商品资料采集组件

独立JST机器入口，源自0.2.0-dev交接包；原件身份与最初文件SHA见upstream.json。
两个仓共用商品导出实现，各自绑定专用浏览器；不使用翱象SessionGate或状态目录。
依赖只读复用相邻aoxiang组件锁定Node和Edge工具；不修改该组件源文件。

启动由主应用传入本机options文件，不提供内置账号、Cookie或密码。账号密码自动登录未实现，正常登录后复用持久状态。
提交前持久记录意图，受理不明保留原状态；首次和恢复均要求按原任务行核验文件链接，无法证明对应关系时停止下载而不取最近文件。

阶段1已增加非阻塞控制接口、单项恢复、提交幂等、账号隔离和只读包内校验入口。尚未完成主应用采用、界面、构建和真实联调，不能单独视为可交付版本。

离线测试：`components/aoxiang/runtime/node.exe --test components/jst_catalog/test/*.test.mjs`。
上游导出范围测试保留原六项预期；第七项由调用未纳入本组件的订单上传函数，改为验证本组件RPC拒绝订单上传。没有引入订单上传模块。

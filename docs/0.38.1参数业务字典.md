# 0.38.1 参数业务字典与 AI 任务锁异常处理

## 怎么使用

软件的参数维护与完整参数页面、MCP 和 CLI 共用参数说明。业务人员仍可直接在原参数页面操作，无需学习参数键名。

AI 先通过工具列表了解能力与权限，按软件复制的业务提示词检查工作台，再查询参数。`parameter_definitions` 返回 28 项说明，按分仓周期、分类权重、分类参数、门店通用参数、补货策略、全局分类映射分组；每页最多 100 项，可按组或关键词查询。当前公开工具共 14 个。

`effective_parameters` 仍返回各店的实际值、配置值、来源和签名；每个参数增加 `definition_id`，通过同一响应的 `guidance.definitions` 查说明。多店共用的说明只返回一次。不得把字典中的说明或范围当成该店已经采用的值，也不得把已登记文件当成已检查通过。

可直接给 AI 的例子：

> 先核对当前工作台，再查询所选门店本次实际参数。根据参数字典，用中文解释备货天数、到货天数、概率系数和分类权重的作用、来源、可调范围与依赖。先只查询，不改配置，不运行计算；指出哪些分类覆盖会使通用参数调整不生效。

## 接口示例

启用软件内的本机连接后，可通过同包的 CLI 查询：

```powershell
& '.\AI接口\补货助手AI接口.exe' call parameter_definitions
& '.\AI接口\补货助手AI接口.exe' call parameter_definitions --arguments-file '.\参数查询.json'
```

参数查询文件示例：

```json
{"group":"parameters","search":"概率","offset":0,"limit":50}
```

字典描述业务作用与调整方向、数值范围、联合约束、单位、允许的继承标记、试算可编辑性、说明来源。`path_template` 中的 `{仓库}`、`{分类组}` 是模板，不能直接提交；使用门店参数结果提供的真实 `path`。

例如概率系数 95% 的接口值是 `0.95`，不能传 `95` 或 `"95%"`；软件的百分比输入框仍按原交互填写百分数。分类参数可用 `"沿用门店"` 取消覆盖。此前16天权重由两项已填写权重推导，不直接修改。固定30天阈值、预算、主从仓、策略开关、全局映射不因这次字典接入变成可由 AI 数值试算修改的项目。

## 实现与边界

- `parameter_schema.HELP`、`WEIGHT_HELP`、`restock_policy.HELP` 提供原业务说明；`parameter_guidance.py` 统一中文展示、约束描述和引用。合法性仍由原校验器决定，字典不是第二套计算或校验实现。
- 原表单可能使用比服务更窄的输入范围，保持原样。例如界面范围不因字典披露服务上限而放开。
- 通用参数与分类覆盖分别解释；分类映射全局共用，分类参数按店维护，周期按仓维护。历史值与来源取当时快照，现行字典不能证明历史规则。
- AI 的试算权限不等于保存默认、签发、采购、删除或控制定时任务的权限。没有开放新的平台操作。
- 提高参数并不保证每个商品都会多补，必须在相同输入上试算；库存、箱规、预算和准入仍可能限制结果。

## 本轮测试发现的锁占用

首次源码 GUI 验收在独立 QA 库触发 `automation_tasks.Journal.update` 提交时 `database is locked`；随后异常分支又尝试写失败状态并再次报错，弹出用户截图中的通用警告。未确认具体持锁进程，不能把原因归到用户数据或单纯的测试并行。单独重跑成功不作为修复证据。

修复让后台结果、进度、门店事件和失败回调统一受控：写状态失败后本任务标为未完成，停止后续处理，原预览不能继续计算或采用。界面及 `task_status` 可查询 `failed` 和 `status_persistence_pending`；持锁期间不宣称成功。每秒尝试一次零等待的失败状态写入，释放锁后保存失败状态及一个事件。只重试回滚后的任务元数据事务，不重跑计算、采用、签发或平台请求。新检查需新的操作键；原键继续指向原失败任务。

没有强制解锁、修改数据库日志模式或迁移存储。若关闭时锁仍未释放，本会话的详细失败状态可能尚未落库；原数据库任务在新会话按既有中断处理，本地诊断日志保留。无法写数据库等非占用错误保留诊断，不无限重试。

## 可复跑验证

使用项目锁定 Python 环境；以下命令写独立 QA 目录，不读取日常作业作为测试输入：

```powershell
python -X utf8 -m unittest discover -s tests -p test_parameter_guidance.py -v
python -X utf8 -m unittest discover -s tests -p test_automation_lock.py -v
python -X utf8 -m unittest discover -s tests -v
python -X utf8 tools/verify_parameter_guidance.py freeze --qa qa/your_new_guidance_run
python -X utf8 tools/verify_parameter_guidance.py before --qa qa/your_new_guidance_run
python -X utf8 tools/verify_parameter_guidance.py after --qa qa/your_new_guidance_run
python -X utf8 tools/verify_parameter_guidance.py compare --qa qa/your_new_guidance_run
python -X utf8 tools/run_automation_ui.py --out qa/your_new_guidance_ui
python -X utf8 tools/run_automation_ui.py --exe '交付_0.38.1_rc1/补货助手/补货助手.exe' --out qa/your_new_guidance_exe
```

原始真实样本须按项目既有验证输入目录准备；不具备这些输入时不能宣称完成真实数据对照。实际报告见 `releases/0.38.1/rc1`。本轮不声称真实 AI 自然语言理解准确率、真实平台联调或全新电脑可复现构建。

# 0.15.1 默认导出位置

点击窗口右上角“导出设置”，选择默认导出文件夹，然后点击“保存默认导出位置”。关闭程序再启动仍会自动带入。每次导出仍可临时选别处，临时选择不会改变默认值。

设置窗口同时显示配置文件完整路径，可复制路径或打开配置文件夹。普通运行保存于本机资料目录的 `export_settings.json`，通常为：

```text
C:\Users\lenovo\AppData\Local\YoutuanTools\补货助手\settings\export_settings.json
```

具体以界面显示为准。使用REPLENISHMENT_DATA_DIR隔离启动时，配置也在该隔离目录中。配置不放在EXE旁，程序升级后继续复用；本次不移动整个资料目录或用户数据库。

配置文件为：

```json
{
  "schema": 1,
  "default_export_directory": "D:\\门店补货导出"
}
```

推荐通过界面维护。保存前检查文件夹存在且可写；写入失败保留旧配置。点击“使用系统文档目录”后再保存，可将默认位置改为系统文档目录。点取消不保存任何修改。

适用于：单/多店确认单、内部明细、归档批量导出、完整计算表、签发明细、当时依据、原件下载、门店回传对照、付款/收货/生命周期对照、导入模板，以及手动导出的清单/数据库副本。每种输出原有文件名、子目录、字段、顺序、数据、覆盖保护和确认步骤保持不变。

无自定义配置时，使用原入口可用的起始位置或系统文档目录。默认目录被删除/不可访问或配置损坏时，明确提示后打开本次位置选择，保留配置供修正；不会跳过位置选择直接导出，也不会自动创建一个不同的默认值。

仅增加本机界面偏好；不参与计算参数、签发快照、每日作业或业务指纹。模型仍0.3.3-rules，原0.15.0保留。生命周期说明见同目录的0.15.0订单生命周期.md。

代码：`export_settings.py`负责独立JSON及原子保存，`export_locations.py`负责设置表单和统一保存位置入口。便携验证：`python -m unittest discover -s tests -p test_export_settings.py -v`。实际EXE和现有导出验证以releases/0.15.1对应候选记录为准。

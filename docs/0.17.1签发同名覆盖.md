# 0.17.1 签发单同名覆盖

基于已合并主线 db60859（0.17.0）。模型仍为 0.3.3-rules，仓归属、参数和存储格式不变。

补货出单、订单跟踪批量导出、历史详情导出的签发单，遇到目标目录中的同名文件直接替换，不再要求改文件名，也不追加文件名序号。山东仓、河北仓仍分别导出，字段、工作表、数量、金额和顺序不变。覆盖的是磁盘上的 Excel，不会重写原归档签发或门店回传。

先在同一目录完整写出临时工作簿，完成取消检查后原子替换目标。读取、写入或压缩失败，以及替换前取消，原文件保留。若 Excel/WPS 占用文件或无写入权限，会明确提示关闭文件、检查权限后重试；不先删除旧文件。批量导出仍按原顺序逐份完成，已成功覆盖的文件保留，失败和未完成项按原回执提示。

同一批次内两个门店映射为同一输出文件名的冲突仍拒绝，避免后一个门店覆盖前一个门店。回传、付款、收货、商品资料原件和数据库备份的导出策略不在本次调整范围。

同时修复订单跟踪批量签发导出的只读数据库连接：该操作需追加导出日志，现使用既有可写作业连接，不初始化或迁移数据库。只新增正常导出事件，不改变签发快照、修订、草稿或后续生命周期事实。

独立候选目录：`交付_0.17.1_rc1/补货助手`。保留 0.17.0，本轮仅本地修复和交付；不自动合并或推送。实际验收以 `releases/0.17.1/rc1` 为准。

# 0.48.4 表格空间与签发引导

本版继续包含 0.48.3 的类目、销量、库存筛选和批量改量能力。

## 主表格优先展示

顶部AI入口并入全局导航栏，运行中的AI操作通过“AI任务”菜单访问；作业标题与草稿操作合并，版本信息仍保留。避免辅助导航和重复标题再各占一整行。AI连接和任务行为未改变。

“门店与参数”页把常用的批量开关/预算/供货仓、应用参数方案、编辑所选补货参数集中在一行。保存默认、资料重查、导入导出及详细维护入口收在“更多维护”，初始收起，展开后在有限高度区域滚动，保留门店表空间。原主从仓、预算、参数的编辑动作仍调用原处理函数。

参数单元格改为单行摘要，原完整说明保留在悬停提示，并可通过“查看生效参数”逐项查看；各行编辑与查看按钮继续保留。行高由88调整为72逻辑像素，文字按显示设置跟随字号，不缩小业务字段字体。

本店商品明细页顶部直接显示执行金额、安排款数、地采及排除款数。原金额卡片、人工改量、新品、预算及必卖详情收进“展开金额、预算、人工调整及准入详情”，可随时查看；展开区域限高可滚动。存在准入问题时，维护入口仍在主界面显示，不藏进折叠区。原商品表、搜索、过滤、导出和计算依据侧栏保留。

这是一轮页面空间整理，没有改金额、筛选口径、预算、参数、模型或仓归属规则。完整表单内容未删除，默认显示减少重复说明。其他模块未整体重排。

## 纯签发和签发导出遇到待核对调整

“保留为待核对草稿”不是“应用最终数量”。只要本次选择的门店仍有暂存调整，“确认签发”和“确认签发并导出”都必须停止，不能通过不导出来绕过。

本版在两个入口选择范围后、启动归档工作进程前，直接列出待处理门店名称和编码，提供“打开这些门店的最终清单”。该按钮只打开所列待核对门店，便于补原因、核对预算和风险、点击“应用最终数量”。返回后再次明确确认签发；不会自动继续签发。

取消引导或最终清单不会删除暂存调整，也不会签发。未选门店的待核对调整不扩大到本次范围。原归档和导出底层完整性、并发及待核对校验继续保留。

用户截图中的“门店尚有待核对的签发前调整：CXT20260623”属于这条保护，不是Excel占用、浏览器连接或导出文件导致。0.48.3 已修复导出快速预检漏传待核对状态；本版进一步让两个入口都能直接定位处理门店。

## 验证范围

隔离合成八店表格在1366×900及1280×800逻辑窗口尺寸下量测表格高度，检查维护与金额区展开可达、12号字体显示、折叠导航不改结果。纯签发和导出分别验证提示、打开所选待核对店、取消保留以及不产生签发记录；消除暂存状态后通过真实主窗口的选择、核对、工作进程完成纯签发。该成功样本是显式合成快照，不宣称真实资料准入核验或平台下单。

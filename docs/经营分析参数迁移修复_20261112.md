## 参数怎样使用

从“参数设置 → 下载完整门店参数模板”开始；已有配置可用“通用参数 / 分组导入导出 → 导出勾选门店完整参数”导出后修改。完整文件包含分仓周期、门店通用参数、分类参数、补货策略、供货关系、门店预算。

空白和缺行仍表示保持，0 按实际值校验，数值参数的“系统默认”保留原恢复含义。完整文件可以新增自定义分类组，但必须填齐该组全部权重并通过原有校验；部分分类参数文件仍只修改已有组。

“分类映射（只读）”、预案版本和必卖清单辅助页仅供查阅；导入预览明确说明不写回。旧 V3 全量导出的“分类映射”页也按参考处理，其余有效门店参数可回导。单独的逐店映射导入仍会引导使用全局分类映射入口，不恢复已撤销的逐店映射规则。

三种生效范围没有改变：仅保存默认供以后使用；仅应用本次需要重算变化门店；同时应用则分别写入本次和默认。历史签发不变。非法值、文件预览后变化和并发修改仍会阻止整批应用。

## 迁移怎样继续原任务

原生导出通过保留组件取得完整本地快照，不依赖状态列表最近 50 条的展示限制；组件没有运行时检查其写锁后读取。后台仍在采集时拒绝导出，不强停，也不复制不一致的状态。

确认迁入后，窗口等待后台连接安全退出；等待不会再清掉已确认计划，也不能重复发起新的业务操作。真正退出后沿用原有完整备份、准备目录校验、整体替换及失败恢复链路。

聚水潭任务与原文件随包保存，来源机器的浏览器绑定和核验操作结果不迁移。目标机器已有浏览器配置保留，自动同步先暂停；先在商品资料页核验与原任务一致的仓账号并“确认对应仓并保存”，再逐项继续。原平台任务号、提交次数、文件内容与摘要不变；本机路径按迁移清单重定位。

核验同一身份后只更新原任务使用的本机连接配置，不自动启动任务。不同账号不能接管原平台任务；已经受理但结果未知的仍保留待核，不能借迁移再次提交。已有平台采购和导出不会被撤销。

旧迁移包如果本来没有包含聚水潭资料任务，无法凭空还原。恢复时目标旧任务依然归入整机备份，避免混入新订单；应在来源电脑用修复版重新导出完整包。

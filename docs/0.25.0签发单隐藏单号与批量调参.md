# 0.25.0 签发单隐藏单号与门店批量调参

本次基于 be82ffd7d1510be91550c3eb5fc7658fc614c443，独立分支 `feat/store-parameter-import-0.25.0`。模型仍为 0.3.3-rules，归属 0.5.1；作业、参数及存储格式不升级。

## 签发单

所有新导出及重新导出的门店签发单，三个工作表的“补货单号”U列默认隐藏。单号值保留，V列“决策理由”仍显示；字段、排序、类型、金额、数量不变。门店照常改Q列后回传，系统仍从隐藏列读取关联号。需要核对时可在Excel取消隐藏U列。

不修改历史签发内容、不改已有磁盘文件；内部计算表、归档资料及生命周期其他导出仍按原用途输出。隐藏列不等于删除单号或保密。

## 批量调参入口与最短操作

- “参数设置 → 批量导入门店参数”：默认仅保存门店默认，下次载入该店自动带入。
- “补货出单 → ② 门店与参数 → 批量导入门店参数”：默认仅应用本次作业。
- 两个入口均可选择Excel文件或拖拽多个xlsx，下载最低模板；读取后核对逐店差异，默认取消，确认才生效。
- 已有参数可用“导出勾选门店默认参数”或“导出勾选门店本次参数”输出，修改后回导。只改少数项时，直接删除其他参数列即可。

预览明确选择三个范围之一：仅保存默认、仅应用本次、应用并保存。仅保存不动当前结果；应用后只将有变化门店标为待重算，其他店和历史签发不变。应用本次不会自动保存每日草稿；沿用原“保存草稿”操作。

## Excel填写规则

一店一行，只有“门店编码”必填；名称选填。有已知名称时校验一致，不按相似名称猜店。编码用文本保留前导零、长编码。按表头匹配，列可移动；前20行识别表头，可跨文件/工作表读取。所有文件同一码重复都阻止，不按先后静默覆盖。

| 字段 | 用途与约束 |
|---|---|
| 主仓、从仓 | 河北仓/山东仓；清除从仓填“无从仓”，清除主仓填“未指定”。从仓需有主仓且不同仓。 |
| 河北仓/山东仓备货天数、到货天数 | 分别修改仓周期，两者均非负且合计大于0。空白保持原值。 |
| 预算方式、预算金额 | 未指定/不限预算/限定预算。单独填金额自动设为限定预算；0元确实是零预算。不限定时金额留空。 |
| 启用一箱例外 | 是/否、启用/停用、1/0。 |
| 普通库存额度天数等超参 | 支持完整参数编辑页中可编辑项，校验沿用同一参数契约；模板说明页提供作用和调整建议。 |
| 权重/组名/趋势敏感度、最近7天权重、此前7天权重 | 组必须在该店方案中存在；w1+w2≤1，w3自动计算。 |
| 分类映射/分类名 | 填已有权重组；“清空”移除映射；空白保留。含斜杠的分类名完整保留。 |

空白从不表示0或清除。0按实际数值校验。不接收公式、Excel错误值、未知表头或不完整数字编码。通用备货深度/到货时间不作为可改列，使用各仓周期；极端缺货边界仍固定30。不会修改参数方案库的公共方案。

最低模板只带常用列。导出现有参数包含完整可编辑超参、权重和分类映射。未保存默认的门店导出标准参考值；新增门店默认从标准方案开始。修改已有门店请先导出对应范围的参数以确认原值。

## 原子性、兼容及结构

全批读取、单文件前后哈希检查、逐店完整配置验证、预览后再核验源文件。任一无效行阻止整批；预览可搜索全部差异及错误。

本次应用要求所有门店已载入、不是只读历史且没有正在计算。保存默认可预存新门店。默认值用原SQLite `stores` 表、原JSON配置保存，无迁移；可选门店名称只作显示元数据，后续手工保存保留。保存使用已有 `save_stores(expected=...)` 事务与冲突检查。先整批提交默认再更新当前界面；数据库失败不更新当前店。保存期间后台执行，界面可显示进度，最终事务不强制中断。

调用链：`ParameterScene / Workbench → store_parameter_ui → store_parameter_import → parameter_schema.validate / store_defaults.record → work_repository.save_stores`。计算仍走原 `batch_service → engine → model / one_box_exception / allocation`。

`normal_exports.export`仅增加U列隐藏属性；`store_parameter_import`负责读表、字段映射、补丁、预览差异、模板/参数导出；`store_parameter_ui`负责作用范围、冲突核验和界面应用；`store_parameter_smoke`仅在显式验收参数启动时运行。

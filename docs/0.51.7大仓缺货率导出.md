# 大仓缺货率导出

入口：大仓缺货率 → 设置观测日期、搜索和多维筛选 → 导出大仓报表。

1. 在选择窗口勾选需要的表。已有自定义组合继续保留，另外提供大仓总览、每日趋势、按供应商、按类目和按商品等常用选择。默认只选当前组合；可以全选或清空切面勾选。每个选中组合一张表，每行一个分组。
2. 需要逐商品查看时勾选“附带商品明细”，选择全部商品（含剔除）、纳入基数、已剔除或待核。在“商品与待核”页点击导出，会默认只导出该页当前明细范围，也可以再勾选切面。
3. 商品明细范围只影响明细。报表中的“范围汇总”和各切面仍按当前日期、搜索和多维筛选计算，避免只看剔除明细时把原缺货率改成另一个口径。商品、供应商同时保留编码与名称，编码按文本保存。
4. 选择保存位置后等待完成提示。初始目录沿用全局“导出设置”；临时改选目录不会更改默认设置。导出包含全部匹配数据，不限当前页200行；超出单表行数时自动续表。每张数据表有Excel筛选及冻结表头，百分比是可继续计算的数值。
5. “口径与覆盖”记录日期、搜索、中文筛选条件、明细范围及公式。“已观测范围”列出该日期段已有的仓快照，不表示筛选命中的商品数，也不表示未采日期有库存记录。

导出期间查询控件暂时禁用，防止查询刷新静默取消导出；“安全暂停”仍可使用。取消或写入失败不会发布残缺的最终文件，也不覆盖已有同名文件。需要重试时选择新文件名即可。

本次同时修复了带搜索词查询或导出时的SQLite `ESCAPE expression must be a single character`错误；百分号、下划线、感叹号和反斜线按字面搜索。

大仓缺货率统计规则不变：先剔除虚拟分类含淘汰、仓商品禁用和精确日配标签，剩余商品可用库存≤0计缺货；不要求有月销。未知资料不当作零。大仓数据继续独立保存，导出不下载平台资料、不更新补货和门店缺货率数据。

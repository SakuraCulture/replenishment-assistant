# 0.51.6 经营分析、完整参数与资料迁移

本版将此前已核验的修复纳入独立交付，模型保持0.3.6-rules。升级时安全关闭旧版，完整解压文件夹后运行，不单独替换EXE；旧包保留。

五段分析中，未取得环节资料或全部缺价均保留未知，页面显示“未确认”、Excel留空；已经确认的0仍是0。导出移除供应商资料状态、类目资料状态、五段资料覆盖、维度资料依据四列，保留供应商、类目、业务数值及三种单号。

“参数设置 → 下载完整门店参数模板”提供六类可编辑设置：分仓周期、门店通用参数、分类参数、补货策略、供货关系、门店预算。“通用参数 / 分组导入导出 → 导出勾选门店完整参数”可以现有值为起点。全量参数文件可回导；分类映射与辅助页明确只读，全局映射从独立入口维护。核对生效范围后确认；没有变化会明确提示，本次变化需要重新计算。历史签发不变。

“订单跟踪 → 完整订单迁移”确认后等待后台连接安全退出，之后整体迁入，旧目录留作完整备份。聚水潭来源原任务、文件和任务号随包迁移，目标旧任务不混入。目标机器的浏览器配置保留，同步先暂停；在商品资料页核验原来同一仓账号并保存，再逐项继续。原受理号和提交事实不变；受理未知不重复提交。旧版漏记这部分任务的包无法凭空补齐，应在来源电脑用新版重新导出。

本版继续包含0.51.4销售型断货保底的双零条件、首铺最小量与箱规向上对齐、八个经营切面，以及0.51.5仓绑定纠错和采用保护。本轮不扩大计算、预算、箱规、默认参数、仓归属或删除确认范围。

完整验证使用隔离数据，不调用真实平台。业务电脑、真实账号和低配置环境仍需现场观察。构建源码、实际EXE验收、完整包哈希和主线同步状态以本版 `releases/0.51.6/rc1/交付报告.md` 及 `主线同步说明.md` 为准；旧报告中的未推送状态保留为当时记录。

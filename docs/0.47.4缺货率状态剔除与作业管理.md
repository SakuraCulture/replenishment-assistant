# 0.47.4 缺货率状态剔除与作业管理

本版只扩展“门店缺货率”独立板块。补货计算模型、预算、箱规、主从仓选择规则、平台采购操作均不改变。不开启该板块时不加载本次新增的重算和日志管理能力；每日采集计划的既有启用规则不变。

## 禁采、禁用剔除

页面新增两个默认勾选的开关，可分别取消，也可与原有淘汰品、考核品视角组合：

| 开关 | 依据 | 处理 |
| --- | --- | --- |
| 剔除禁采（含翱象停采） | 留存的翱象原表“补货状态”为“停采”或“禁采” | 同步从缺货数和有销基数中移除 |
| 剔除供货仓禁用商品 | 按该门店主从仓规则选中的聚水潭商品资料，“商品状态”为“禁用” | 同步从缺货数和有销基数中移除 |

“备用”不等于“禁用”，仍保留。未参与供货的另一个仓库状态不参与此判断。双仓切到从仓供货时，采用实际选中的从仓资料。原始状态缺失的商品保留，不能推断为禁采或禁用；在“商品与待核”中可查看原始补货状态和仓商品状态。

多个条件重叠命中只剔除一次。缺货率公式仍为：当前视角中月销大于0且门店可用库存等于0的店品数，除以月销大于0的店品数。负库存和无效字段不被改成0。当前汇总、每日趋势、切面、商品明细及Excel使用同一组条件。Excel保留完整范围明细，并用“本视角剔除”列标记被排除的商品，便于核对；总体和汇总仅统计保留商品。

旧日报已经留存这两个状态字段，可直接切换开关查询，无需重新下载或改写旧数据。开关改变后点击“查询已留存结果”。“清空切面筛选”仅清除切面分组条件，不取消状态勾选。

## 采集与快照中的操作

| 入口 | 作用 | 保留内容 |
| --- | --- | --- |
| 继续原任务 / 补失败项 | 继续原平台命令或本地重算；原已发布采集可补失败项 | 原命令身份、防重保护、已完成原件 |
| 重新采集今日资料 | 按所选作业的门店和当时设置，新建今日采集；重新取得仓资料及门店补货建议 | 原作业及历史日报；日期以实际观测为准 |
| 用留存原件重算 | 选择“当前分析已采用设置”或“原作业当时设置”，用留存原件生成新修订 | 原件、原观测日期和旧修订；全程不连接平台 |
| 删除所选作业日志 | 清除该作业运行消息、逐店错误，并从默认作业列表移除 | 分析结果、原件、版本和平台任务等必要关联；不删除应用总日志 |
| 删除分析数据 | 按页面上方起止日期预览、确认后删除该范围分析快照、各视角汇总和不再引用的门店原件 | 日期范围外结果、共享原件、仓资料、作业记录、补货业务库和平台记录 |

重采会明确展示门店和当日日期；如果今天已有其他门店的日报，所选旧作业范围不足以覆盖，会拒绝覆盖并提示选择完整门店范围。仍沿用既有并行导出管线和任务防重检查；平台受理未知时应继续原任务核对，不能通过新建、删日志或重跑绕过。

重算只接受当前已发布作业，列表中标注“当前日报”和日期，避免较早作业覆盖后来采集的门店结果。若按当前设置重算，该设置须包含原作业的所有门店，并且原作业须留存新供货路线所需的仓资料；否则提示缺少的门店和依据。不会自动更新补货侧资料，不拿今天的仓资料补写旧日报。原来未完成的门店仍保留未完成，不补0。完成全部可重算快照后才原子切换日报；取消、失败或期间日报变动均不覆盖旧结果，可继续原重算作业。

删除日志前先结束未完成作业；已发布部分范围但仍有平台任务的作业，需先点“结束本地准备”核实平台任务已结束。删除日志不会解除平台防重保护。若以后需要重算保留的结果，勾选“显示已删日志的日报依据”，即可选择剩余的结果关联；已经删除的消息和错误不会恢复。

## 删除范围与资源

数据删除按观测日期覆盖**全部门店、全部商品维度和全部剔除视角**，不会按当前类目、供货商或页面勾选偷偷缩小范围；确认框列出快照数、商品记录数和日报修订数。不是按作业创建日期删除。清理完最后一个日期后，页面显示空结果，不残留旧数字。

所有删除都仅在分析自有目录内执行。数据库事务先复核预览范围；原件清理采用可重试记录，取消确认不会删除数据，提交期间等待完成再退出。仍被其他日期引用的门店原件、仓资料和所有补货/平台文件均保留。没有进行全库压缩，SQLite删除后的空闲页供后续复用，因此数据库文件不会立即变小；“删除作业日志”也不等于物理清空数据库页。

已删除的分析快照不能再用作重算；可恢复独立分析备份，或明确重新采集今日资料。无法通过今日采集补回历史库存。不要为了重跑而先删数据。

## 验证与版本

新增验证覆盖组合剔除去重、所选供货仓状态、备用/未知保留、页面与Excel一致性、原件校验、重算取消恢复、旧修订保护、并发复核、日志与结果分离、删除后空态、重新采集及未选门店保护。全部使用隔离目录和模拟平台协议；没有删除真实业务资料、没有发起真实平台导出。

实际完成的回归数量、EXE验证、构建提交和交付哈希见本版发行报告。真实平台连续运行、低配置业务机和大库删除性能没有在本版重新实测，不将功能验证当作性能提升证据。

# 数据保存位置与整库搬迁

0.52.1增加“显示与帮助 → 数据保存位置…”。它设置软件内部资料位置，与“导出设置”的Excel输出目录分别维护。本版整合0.52.0运营签发等业务功能及0.51.10迁移退出、实例识别修复；本次位置功能不改模型、数量、箱规、预算和单据计算。

## C盘空间不足，怎么搬到D盘

1. 使用完整解压的0.52.1程序包，保存当前草稿，等待业务任务安全结束。
2. 正常关闭本应用的采集专用Edge窗口。日常浏览器无需关闭；应用不会强杀浏览器或提交任务。若无法确认浏览器占用，本次搬迁会停止并说明原因。
3. 打开“显示与帮助 → 数据保存位置…”，核对当前资料位置。
4. 选择D盘或其他本机磁盘中的独立空文件夹，例如`D:\补货助手资料`。可由软件建立最后一级目录；不覆盖现有资料、不混合另一份库，不使用磁盘根目录或网络共享。
5. 点击“校验位置并搬迁全部资料…”。核对旧位置、新位置、文件数量和恢复副本位置后确认。取消确认或取消未保存作业提示，均不搬迁。
6. 等待软件安全退出、复制、核对文件摘要及数据库完整性、切换位置和归档。默认结束后自动重开；搬迁中再次启动只显示原操作状态，不开第二个写库窗口。
7. 重新打开后核对结果提示及“数据保存位置”，再抽查已有订单和缺货率日期。订单和原版本保留，不重算、不重新采购。

新盘至少需容纳一份活动资料和一份完整恢复副本，并留出校验余量。预检按当前资料大小的两倍加128 MiB检查；复制期间资料增大仍会重新核验。时间取决于实际文件数量、盘速和归档量，没有承诺固定秒数。

## 一起搬哪些资料

包括软件资料目录内的订单及所有修订、草稿、回传、运营签发、库存分配、付款、实收、平台关联、防重记录、采集原件、门店/大仓缺货率、参数、日志、本机AI登记、专用浏览器资料，以及资料目录内的旧备份和待迁入材料。历史单据内容和摘要不重写；旧绝对路径通过目录兼容链接继续访问新位置。

仅用于同一台电脑、同一Windows用户调整磁盘位置。浏览器及登录资料不应复制给其他用户；换电脑仍使用原有“完整订单迁移”流程。资料目录之外的Excel导出文件保持原位，可另外更改“导出设置”。外部选择的浏览器资料夹不会被一起移动。

系统盘保留少量启动定位、恢复记录、实例锁及旧目录兼容链接。链接本身不存另一份业务库。请勿手动删除、重命名或重新建立旧位置目录；搬迁后使用新版完整程序包，旧程序归档保留，不应同时运行。

## 恢复副本与异常处理

恢复副本为新位置旁边的`资料目录名.恢复副本-操作号.zip`，包含完整文件清单、SHA-256和原目录内容。程序逐文件验证归档后，才按本次记录清理旧位置副本；变化或新加入的文件不会被猜测删除。归档或清理失败时，新位置仍有效，完整旧副本保留，结果显示“旧位置副本待归档或清理”。再次进入本页点击“继续归档并清理旧位置副本…”，可安全继续。恢复副本含本机登录资料，请妥善保管。

切换前失败或中断：保留复制材料，恢复原位置，不自动重放；排除占用、空间或权限问题后使用新的空目录重新校验。切换提交后中断：核实新位置身份，继续使用新库，旧副本保留待清理。磁盘暂不可用：明确提示接回资料盘，不回退C盘建立空库。

本版没有一键还原恢复ZIP入口。需要回退时先关闭应用、保留当前新库及完整ZIP，结合`manifest.json`和本机位置记录执行单独核验的恢复，不把ZIP覆盖到正在使用的目录。

位置配置和过程日志在`%LOCALAPPDATA%\YoutuanTools\data-location`；错误包含原始异常和阶段。状态区分准备、等待退出、复制/校验、切换提交、归档、完成、失败。退出清理阶段只记日志，结果由下一次正常窗口提示，不在已销毁的Qt应用中弹窗。

## 验收边界

测试使用新建合成库、独立LOCALAPPDATA和本机C→D跨盘目录，不调用真实平台。真实迁入/恢复、真实业务电脑搬迁另行执行；交付报告列明中间失败、修复后的源码与实际EXE证据。未提交、推送、合并或替换用户正在运行的软件。

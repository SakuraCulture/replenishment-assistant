# 0.19.1 核对与签发：人工改量和新品金额

第④步新增两项金额，在门店汇总、逐店列表及本店明细顶部均可查看。

| 名称 | 口径 |
| --- | --- |
| 人工改量商品最终金额 | 已应用的直接人工改量商品，按最终执行金额合计；改成0的商品仍属于人工改量范围 |
| 较自动安排增减 | 上述商品的最终金额，减去人工改量前保存的自动安排金额；增加用正号，减少用负号 |
| 新品商品最终金额 | 与签发单的“本月新品＋往期新品”商品范围一致，按预算和最终调整后的执行金额统计 |

例如某新品自动安排6元，人工改为10元：人工改量金额为10元，较自动安排+4元，新品金额也是10元。两项交叉，不能相加算成20元。

使用方法：

1. 完成计算后进入“④ 核对与签发”，直接查看本次有效完成门店的合计。
2. 逐店表格中，“本次安排”右侧为“人工改量金额”“新品金额”。人工金额下方直接显示增减额。
3. 点击这两列可进入对应商品范围；人工改成0的行仍可查看，新品未安排的0数量候选也保留。
4. 本店顶部显示整店金额，不随下面的仓库、分类和搜索筛选改变。筛选结果金额仍看原来的“当前筛选”行。
5. 在最终清单中应用或撤销人工调整后立即更新；只保存待核对调整而未应用时，仍展示当前已应用结果，并保留“待核对、不能直接签发”提示。

边界：

- 直接人工改量以现有 `kind=manual` 调整记录为依据。新品／计划／活动清单补足仍保留各自来源，不混入直接人工改量金额；其中符合签发单新品分组的商品计入新品金额。
- 未计算、失败和待重算门店不计入有效合计；对应单元格显示“—”。
- 地采、禁用和停采不计入这两项；预算未安排的新品按最终0量计算。
- 缺价／未知金额标明“已计价”及待核款数，不能理解为整组金额已完整；旧记录缺自动安排金额时标注增减待核，不补造依据。
- 本次只新增界面统计和筛选，不新增存储字段，不修改计算、数量、预算、归档或Excel字段/顺序/样式。模型仍为0.3.3-rules。

实现索引：`review_amounts.py` 为只读口径、格式和缓存；`ui_review_amounts.py` 为公共金额栏；`batch_app.py` 为汇总、表格及点击入口；`ui_results.py` 和 `ui_goods_fast.py` 为本店展示与筛选。缓存绑定当前结果对象，应用、恢复和重算产生新结果时自动失效。

# 0.53.5 订单经营分析双模板导出

订单跟踪 → 经营分析 → 查询后，导出菜单统一为两项。

## 订单经营分析

按业务提供的订单完成情况模板，输出SKU种类、商品货值、商品数量三张工作表。每张表先放大盘与比率，再列逐单数据。每笔仓单有ALL、必采、非必采；当时必采属性未留存时增加属性待核行，ALL包含该组。全待核、全排除的订单也保留身份行。

顶部只汇总ALL，不叠加分组；SKU按每笔订单内的商品计数，再跨订单相加。八项比率按对应分子分母重算，不平均百分比、不封顶。Excel筛选不改变顶部大盘，查询或勾选范围会影响导出的大盘。

## 订单经营细则分析

按业务提供的单页SKU模板，输出一张“SKU完整明细”。主体41列顺序保留：身份与商品、六阶段数量、八项比率、统一单价与货值、商品属性、门店库存与约束、大仓库存与供货商。表末追加此前要求保留的聚水潭内部订单号和翱象采购单号；汇总也同样保留。模板“订单编号”即原签发仓单号。

门店列显示名称（编码）。商品编码、条码和外部订单号按文本存储，保留前导零，不把公式形状的名称当作公式。明细保留当前查询的纳入、待核和排除行，在订单状态里说明范围和实际原因。

## 字段依据与边界

- 六阶段为模型建议、签发、门店回传、运营回传、付款下单、实际收货。运营取实际运营签发文件，未留存不以门店回传替代。
- 统一计价单价取签发时冻结V；货值等于该单价乘各阶段数量，不等于付款原表实际金额。
- 门店现货、月销、在途、条码、供货状态、库存更新时间取当时冻结输入；供应商与分类沿用冻结仓资料。模板“三级类目”保留仓资料分类原文，不用快销/慢销参数分类代填。
- 大仓可用库存取对应仓的当时冻结资料或同份归档原件，库存原件重复、冲突或未留存时不填当前库存。它不是本次在线刷新结果，也不表示某次分配扣减后的余额。
- 目标持有量取当时预测含安全库存目标BF；BF未留存但AP与AL均有合法值时使用AP+AL。最低持有量仅取冻结必采持有依据的minimum，不用BQ最低恢复补货量冒充。
- 未知显示n.a.，明确0保留0，原始负库存按原值保留。汇总任一应纳入商品阶段资料不完整时不以已知部分冒充完整合计；排除行不入统计。空必采/非必采子组为0。
- 数量合计是不同商品库存单位的执行量之和，不表示统一物理单位。模板不增加天数表，原天数和趋势的查询能力仍保留。

## 操作与安全

“导出当前范围”沿用查询及下钻范围；“导出所选订单”仅导出明确勾选的仓单。采用全局导出目录，文件前缀分别为订单经营分析、订单经营细则分析。

文件包含公式及即时可读的缓存值，筛选、冻结表头、样式和分区按模板整理。导出前后均复核同一分析快照，取消、并发更新或失败不会发布半份报表；同名文件仍拒绝覆盖。只读历史取数，不重新计算补货、不改变单据、不读取当前资料补历史、不调用平台。

本版包含0.53.4已交付的计数解释和采购付款本地预检修复。原交付、模板原件和验收证据均保留。

# 核验异常与补货建议采集流水线

基线：4092a1c；本轮在独立分支 fix/aoxiang-setup-pipeline 修改。应用仍为0.24.0候选，模型0.3.3-rules不变；新构建ax_rc4，保留ax_rc3，不推送、不合并。

## 操作变化

配置窗口的浏览器检测完成不再显示门店核验100%。勾选门店后核验；界面显示当前步骤及已等待秒数。连接与身份合计默认上限120秒，每店只读核验默认上限60秒，沿用已保存浏览器超时参数计算上限。停止立即中断只读核验等待，释放本次执行器，不关闭用户Edge、不保存未通过配置。

状态查询异常只提示一次并停止自动轮询；可点“异常后重新连接”，等待原只读连接结束，再检测、重试。身份、网络、页面超时和未知浏览器错误终止本次核验，不对所有门店重复等待。只有明确门店编码/名称不符类错误允许继续其他门店。步骤失败、取消和连接清理期间均不能保存。

获取建议改为两个阶段：先按所选顺序查询并逐项提交导出，取得真实受理任务号后继续下一店；再轮询所有已知任务，哪个完成就下载、校验和留存哪个。首店慢不会挡住后店已完成文件；所有门店处理完后，仍按原所选顺序交给检查/计算入口。等待预算默认15分钟，耗尽时保留已完成和已受理任务，用户可继续原采集任务。

## 保持的边界

- 平台生成文件可以并行；同一个网页的筛选、查询、提交、历史任务操作仍互斥。文件下载/校验暂为逐文件，不宣称同时下载多个文件。
- 逐门店保存意图、受理号、实际编码和原始范围；查询和下载按精确任务号。不能按“最近N条、数量一致”认领，外部任务或乱序完成不能混入。
- 受理未知、错误范围和身份变化保持中断/待核，不能自动重提。暂停停止新动作，已受理任务保留；采购上传取消边界未改变。
- 不改销量、单位、价格、箱规、仓路由、预算、计算、归档或导出。原业务存储格式不迁移；新增phase/task_id仅是采集进度，不是模型字段。
- 未改原Excel、用户配置或历史库；所有验证在独立QA目录。本轮不操作真实平台、不创建采购、不启动周期任务。


输出目录须不存在。流水线工具从固定基线导出旧调度源码，以同一合成原生Excel、同一运行时交替运行新旧版本各3次，经过真实协调器、任务库、工作簿校验、发布和不可变副本保存。严格比较结果值、类型、门店顺序和完整文件字节；仅忽略每次随机run_id和隔离QA绝对file路径。模拟外部最新无关任务，禁止认领。

该性能试验是本地模拟：每店查询20ms、首店平台生成700ms、其余400ms。结果只能证明调度效果，不代表真实翱象服务耗时、限流阈值或生产提速比例。真实多门店并行生成、浏览器授权和完成单实收仍需现场验收。实际EXE验证单独记录，模拟异常不冒称真实断线复现。

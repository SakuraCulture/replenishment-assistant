# 0.52.9 回传重复商品核对与准确定位

同批导入时，实际冲突文件与当前高亮行可能不同。旧窗口在错误后附加高亮行的来源，因此河东文件失败会被显示成定陶。本版错误由实际处理的来源单携带文件名、环节、订单号；商品冲突列出全部工作表、Excel行号、数量和差异字段。

## 使用

1. 订单跟踪进入回传或其他生命周期单据导入，勾选本次完整来源单，点击“核对并准备保存”。
2. 同一仓单的同一商品存在不同数量、金额、名称等内容时，打开“选择重复商品的最终明细”。每款选择最终采用的原始行；下拉框列出工作表、Excel行号、数量，付款行同时列出金额。
3. 默认不选。明确填0与正数量都可采用；软件不取最大值、不累加，也不按工作表名称猜测哪一行正确。全部冲突选择后点击“采用所选行并继续核对”。
4. 在原核对页检查整单、缺行、清单外和数量变化，明确确认后保存。本窗选择原行不等于保存。
5. 之后进入该环节单据版本，点击“查看重复商品采用记录”，可见已采用与未采用的来源、原数量、原金额；原文件仍可完整下载。

返回文件范围、重新读取、重映射或再次预览时重新核对选择；取消不保存任何单据。相同文件、相同选择重复导入不累加、不新增相同版本。选另一行属于一次明确更正，按原生命周期规则留存新版本。

## 边界

- 只消除同一完整来源单内的冲突；不同订单、不同仓、不同单据号或日期不拼单。多份整单候选仍由原入口明确选择一份。
- 数量、单位、换算、金额和名称整行采用；付款数量与金额不从不同候选拼凑。未采用行单独保留采用记录，不伪装成同值重复。
- 同值重复维持原行为：去重并保留来源，不相加。空白与明确0保留各自含义。
- 原件在预览后变化、原签发修订变化、并发更改、取消和提交回滚保护继续保留。
- 不修改补货计算、默认并发、箱规、预算、仓归属或原签发。测试只用隔离合成资料，不导入真实业务数据、不调用平台。

## 原始问题核查

只读核对所提供定陶文件2040行，没有重复商品编码。截图同批河东(1)文件1696行中10款在“往期新品”及“中心仓动销补货清单”重复且数量不同；商品5009034892013对应第46行0与第475行1。原始河东未带(1)文件1686行无重复。此事实只能说明两份文件的差异，不能据此认定重复来自导出还是后续编辑。

本版不会自动决定门店最终要0还是1，也不会改写这些原件。源码、打包和验证证据以独立0.52.9交付报告为准。

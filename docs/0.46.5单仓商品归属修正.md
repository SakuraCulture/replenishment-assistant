# 0.46.5：单仓商品按本次供货范围归属

单仓作业只按本次所选仓判断中心仓商品归属。此前会额外检查已导入但未选用的另一仓：本仓没有、另一仓有的商品因此显示“归属仓未匹配商品资料，价格与箱规待核”。本版将这类商品归为本次地采，不再仅因另一仓有资料要求核对。

| 本次设置 | 所选仓商品资料 | 另一仓商品资料 | 本版处理 |
| --- | --- | --- | --- |
| 山东单仓 | 有 | 任意 | 山东仓，使用山东仓资料 |
| 山东单仓 | 无该商品 | 有或无 | 本次地采 |
| 河北单仓 | 有 | 任意 | 河北仓，使用河北仓资料 |
| 河北单仓 | 无该商品 | 有或无 | 本次地采 |
| 主仓加从仓 | 任意 | 任意 | 保留原双仓路由规则 |

“无该商品”指已成功导入并校验的本仓商品资料中没有该编码，不是本仓库存为零。本仓有商品但库存为零、禁用、停采或库存未知，仍按原规则处理。本仓整份资料未导入仍阻止计算；无效或重复编码、非数字销量等问题仍待核。不会借用另一仓价格、箱规或状态。

本次地采不进入中心仓下单，也不等于已取得地采报价或已完成地采采购。原标准资料缺少地采价格时继续保留缺价，不能当作0。批量选品与铺货入口保留，地采不能强行安排本仓出货。

## 升级与重算

正常退出旧版，完整解压本版交付包，运行其中的补货助手.exe。保留整个目录以及旧版交付。

已经算好的草稿需按原流程重新计算，才会采用本次归属规则。历史签发单保留当时快照，不自动修改。跨天或已签发的只读历史不在原地改写；新作业使用本版重新计算。

## 版本与验证

应用0.46.5，仓归属能力0.5.2；模型仍为0.3.4-rules，参数/作业/存储格式仍为3/1/2。仅单仓地采行的归属审计使用0.5.2；双仓及未变化的匹配路径保留原审计版本。

生产业务修改位于 `src/warehouse_catalog.py:route_store`。新增单仓专项测试和冻结旧引擎对照，实际EXE沿原分仓导入、计算、导出及默认设置恢复流程验收。结果以 `releases/0.46.5/rc1/交付报告.md` 为准；没有调用真实平台、修改真实业务数据库或重测删除性能。

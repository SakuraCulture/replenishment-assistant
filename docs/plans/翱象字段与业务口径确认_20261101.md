## 3. 采购导入模板的固定写入关系

`sheet1!A7:L7` 为 12 列表头，第 8 行起写业务数据。原第 8、9 行是示例，生成时清除示例内容；保留格式、说明及隐藏验证选项。隐藏表 `hidden_sheet1_col_10` 在 K3001/K3002 保存“是/否”。

| 模板字段 | 来源和处理 |
| --- | --- |
| *仓库/门店编码 | 当前订单对应的翱象门店编码 |
| *供应商编码 | 山东仓 `ZXC2025`；河北仓 `2078246` |
| *商品编码 | 已确认付款单商品编码，文本精确使用 |
| *采购数量（基础单位） | 已确认付款数量，直接使用基础单位，不再换箱 |
| 采购单价（元） / 采购金额（元） | 使用已确认付款依据；模板注明两者都填时金额优先，不让平台最新价替代本次价格 |
| 物流单号 | 有真实来源才写，没有留空 |
| 商品名称 / 规格 | 有来源则填，辅助核对，不作为关联键 |
| 网采订单留言 | 可带本地补货单号帮助人工查阅；同门店供应商保持一致；不作为可靠幂等键 |
| 是否创建外部订单 | 明确填写“否”，只创建翱象采购单 |
| 外部采购账号 | 本范围留空 |

批量选择多张本地单时，按本地门店/仓订单顺序逐单生成、上传和绑定，不混淆两仓供应商。本轮不开发超上限拆单处理；若意外返回多单，只保留证据并待核，不能丢弃或重新上传制造重复单。

## 4. 采购子单字段及状态

以下位置来自本次文件核查，用于解释当前样本；实现读取优先使用已验收的字段名，保留原位置与来源追踪。

| 列 | 字段 | 用途 |
| --- | --- | --- |
| A | 采购订单号 | 与本地已保存的翱象采购单号精确关联 |
| B | 单据状态 | 保留平台原状态；“已完成”停止常规监控 |
| H | 仓库/门店编码 | 防止读取其他门店订单 |
| J | 供应商编码 | 核对当前订单的供货仓供应商 |
| M | 商品编码 | 商品明细精确关联 |
| P | 基础单位 | 记录与核查用户已确认的单位口径，不执行额外换算 |
| Q / R | 箱规 / 包装单位 | 辅助展示，不能当作再次换算依据 |
| S | 采购数量（基础单位） | 采购基准数量 |
| V | 实际入库数量 | 实际收货数量；空值与 0 分开 |
| W | 采购价（基础单位） | 采购价格核对 |
| AA | 单品采购金额 | 商品采购金额 |
| AF | 单品入库金额 | 商品实际入库金额 |
| AO / AP | 创建时间 / 更新时间 | 来源时间；均不能自动冒充实际完成时间 |

样例只证明“已建单 / 待提交”的情况：采购数量 S2 为 1，基础单位 P2 为袋，实际入库数量 V2 为空，F2 入库总金额为 0.00。不能从总金额 0 推断缺失的入库数量为 0，也不能把“待提交”解释成上传失败后自动重传。

主单与子单状态一致时按该采购单状态推进。观察到可信的“已完成”终态后持久保存停止监控及最终同步待办；若最终主子状态或明细冲突，保留待核，不恢复常规监控或强行写实收。未完成订单继续观察；平台后续提交和收货动作由业务人员执行。

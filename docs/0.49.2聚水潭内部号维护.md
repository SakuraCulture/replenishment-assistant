# 聚水潭内部订单号怎么补填或修改

适用：付款已确认，但还没登记聚水潭内部订单号，或者原号码填错了。已经采购、已经收货的订单也可以维护。

1. 打开“订单跟踪”，找到订单，点“查看订单详情”。
2. 在“单据与依据”中点“维护聚水潭内部订单号”。
3. 核对页面上的门店、仓和补货单号，填写或粘贴聚水潭内部订单号。
4. 点“保存”。窗口关闭后，订单详情显示已保存的号码。

只有一个输入框，不需要重新导入付款文件、选择企业或重新认单。订单必须先确认付款；尚未付款时入口不可用。

再次打开会带出已保存的号码，可直接修改。点“查看修改记录”可看到原号、新号与时间。点取消或关闭窗口不会保存；原号码不变时重复保存也不会新增记录。

这里登记的是本机订单的聚水潭内部订单号。付款金额、数量、版本、翱象采购关联及收货依据保持原样；原付款文件及历史版本中的单号也不覆盖。此入口不查询或修改聚水潭平台，不改变付款自动认单规则。

原付款文件已有内部号时会自动带出。暂存过修改的本机登记值优先显示。号码按文字保存，保留前导零；最多100字，不能包含空格或换行。若提示“订单、付款或内部号已更新”，关闭此窗口重新打开，核对最新号码后再保存。

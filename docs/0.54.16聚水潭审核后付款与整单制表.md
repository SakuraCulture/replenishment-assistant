# 聚水潭审核后付款资料与整单制表

在「订单跟踪 → 聚水潭导入单 → 自动下单」查看下单与审核结果、线上单号、内部单号和付款资料。查回普通审核状态「已客审待财审」后，程序按原企业、仓账号、店铺和两个单号读取整单。页面列出原分配和审核后商品数量、成交商品金额、运费、平台应付及差异。商品金额按平台明细保留。运费和无法解释的优惠或其他差额单独提示。

在原下单任务用「补取付款资料并核对」，也可从「付款核对 → 核对聚水潭付款资料」进入。同一份完整明细重复读取沿用原候选。断线后沿原内部单号补取。正式付款保存前会重新核验原单并检查本地版本。业务在实际付款后勾选确认，保存正式付款单。历史销售出库来源可从「历次付款资料」查询。

较短的商品串沿用原多商品表。超过 32,767 字符时用「单商品」格式，每款商品一行，复用同一线上单号。数量按原分配，单价留空由平台取当前基本售价。平台预览须核出唯一一张订单、同一标识、完整商品数量、可核验金额及收货资料。若出现拆单、资料缺失、同名商品无法区分、超出 3 MB 或 30,000 行，保留原生成单供核对。

恢复原任务时，导入结果待核的单先用「核对原单」。普通审核或付款资料已就绪的仓单继续使用其原内部单号。业务确认付款后可生成翱象采购预览。正式提交由业务人员处理，到货后按原采购号同步并保存实收。

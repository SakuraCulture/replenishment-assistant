# 0.29.0 极端恢复与新品铺设开关

基线：main `21d6d7f2937e03261e3492c8dd8b1f70fa3af25a`，应用0.28.0。独立分支 `feat/restock-switches-0.29.0`。
本次应用0.29.0、模型0.3.4-rules、参数schema3；仓归属0.5.1、作业schema1、存储格式2不变。两个开关缺省均开启，不回写旧快照，不迁移SQLite表。

## 操作位置

1. 参数设置：勾选门店→“批量设置默认补货策略”，只影响后续默认。
2. 补货出单②门店与参数：勾选门店→“批量调整补货策略”，选择仅本次或同时保存默认。已有结果失效，重算后生效。
3. ④核对与签发：“调整补货策略”，或本店明细“调整本店补货策略”。后台试算→开关/门店金额/逐商品/风险四页核对→确认应用草稿→签发。
4. 完整参数方案也保存开关；门店参数Excel增加“极端缺货自动恢复”“新品铺设”两列。按表头识别，开启/关闭，空白保持原值。

专用批量入口只改选中的开关，未选项保持各店原值，不统一仓周期、权重、预算或供货顺序。两仓共用。普通参数编辑仍是完整表单，其原有逐店差异核对不变。

## 规则边界

- 极端恢复：有效缺货天数≥30时，仅控制最低恢复量生成。关闭不把缺货天数改0，不转入普通预测；原始数据和极端分类保留。缺箱规等待核情况不能因关闭变成健康0。
- 0<N<30普通恢复、有销量双零最低持有、箱规倍数、禁用/停采、一箱例外、仓路由和预算优先级保持。
- N>30且J>0仍废弃冲突缺货天数，按原销量公式计算，不受极端开关影响。
- 新品开启只允许选品，不自动全选。关闭限制安排新品、清单新品补足和人工给现有新品候选加正数量。计划/活动或人工操作也不能给符合现有新品判定的商品绕行加量；普通商品调整保持。
- 只切换新品复用计算基础，仅重做新品与预算；切换极端恢复则重算相关门店。此前普通人工调整保留，重新核对风险；关闭新品移除相应正数量安排，并列出变化。
- 原预测量、预算前候选、预算执行、人工最终量分别保留。释放预算可能改变其他商品执行量，不承诺总金额按恢复金额同比下降。
- 新品识别及关注清单、本月/往期分组、零数量候选导出规则不变。正式签发列和样式不变。
- 已签发单只读；调整草稿不更新历史签发，需再次明确签发。旧模型草稿沿既有跨模型只读/复制重算流程处理。旧版本程序不保证理解关闭开关的新草稿，请勿用旧EXE编辑新作业。

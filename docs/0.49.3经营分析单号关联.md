# 门店经营分析：三种单号一起查看、保存和导出

业务目标：从一行经营分析追溯原签发单、聚水潭订单及翱象采购单，避免到不同页面重新拼单号。

1. 打开“五段经营分析”，选业务日期、门店、仓和必采属性，点“查询”。
2. “门店汇总”“门店分仓”“订单漏斗”在门店、仓后并列展示：签发单号、聚水潭内部订单号、翱象采购单号。切换可售天数视图也保留。
3. 门店汇总可能包含跨日期、跨仓的多张签发单。三列从上到下按签发仓单对应；同一签发单有多个外部号时用顿号分隔。缺少聚水潭号显示“未提供”，未关联翱象号显示“未关联”。可双击逐层下钻到订单，或右键查看当前行完整内容。
4. 选“门店经营分析（含可售天数）”，点“导出当前范围”。只需要部分订单时，在订单漏斗中勾选后点“导出所选订单”。
5. Excel 的“门店经营对比”“门店分仓对比”“订单五段漏斗”在原42列之后追加这三列，共45列；原五段指标、格式及可售天数列位置保留。商品明细导出也追加三种单号。
6. 同一文件另有“单号关联明细”：按签发仓单保留业务日期、门店编码和名称、仓、三种单号、来源、已留存平台状态和付款版本。多张翱象采购单分别留行；跨日、跨仓不会合成一个采购号。号码按文本保存，保留前导零。

签发单号就是原补货仓单号，例如同一父单下的山东仓和河北仓分别使用自己的仓单号，不用另一仓的号码代替。

聚水潭号优先使用“订单详情 → 维护聚水潭内部订单号”已保存的值；未补填时使用当前付款原表中的内部订单号。只有本地生成文件而未拿到真实内部号时，仍显示未提供。补号直接在原订单详情填写并保存，随后返回分析页重新查询。

翱象号来自本机已保存的采购关联，并核对原订单身份、签发修订、仓和签发快照。只受理了任务但尚未取得采购单号的，不拿导入任务号冒充；同名门店、同号重建或其他仓的记录不会混入。旧关联所据付款版本变化时，单号仍留存，同时在“单号关联明细”标明待复核。已作废采购单保留原号，并显示本机已留存的作废状态；本页不会为查询单号发起平台操作。

查询时三种单号与指标进入同一快照，导出保存该次对应关系。补号或采购关联、已留存状态变化后，先重新查询再导出；不会把新单号悄悄填入旧报表。报表中极长的汇总号列表若超过单元格可容纳范围，会指向“单号关联明细”，完整号码仍逐单保存。

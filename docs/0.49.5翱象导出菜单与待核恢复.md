# 0.49.5 翱象导出菜单与待核恢复

## 业务操作

获取翱象补货建议时，程序会在提交前重新展开“全部信息导出”菜单，再检查可见、可用、唯一及未被其他弹窗遮挡。只派发一次点击，不强制点击隐藏控件，不自动重复提交。

若明确在派发点击前失败，提示“本次未点击提交”，原意图留档为提交前停止。点击“继续原采集任务”可重新核验范围并继续，不需要删记录或重配连接。

若页面操作期间断开或请求已发出而没有可靠回执，继续保留“平台受理需核对”。初次出现仍立即停止后续提交，防止异常页面连续操作。随后可点 **核对原回执 / 继续其他门店**：

1. 已经可靠保存原任务号的项接回原 run，沿原任务下载和完整校验，不重新导出。
2. 仍无回执、范围错误或存在多个任务号的门店继续保留保护，不提交。
3. 原批次其他等待中的门店继续按原顺序处理；已经成功的文件保持。
4. 其他门店处理完后，可“采用已验收文件并检查”，待核门店在采用清单中明确列为未纳入。

结束、删除仍不允许丢弃受理未知记录。普通“继续”和“重跑”协议仍不能重派待核项；新增专用恢复动作 `collection.continue`，不接受 force 或清除保护参数。

## 已经卡住的旧版记录

旧版的 `UI_ACTION_TIMEOUT`、空任务号以及历史列表暂未找到，都不足以证明没有提交。旧记录升级后不会自动被标为“未提交”。本版可以继续同批其他门店；若原回执已保存则接回原任务。没有可靠回执的门店，需要核对原平台导出历史和原件，不能自动按“最新一条”、数量相同或店名相近认领。

业务急用时，核实平台已有文件的门店、范围后下载，通过补货出单“添加文件”检查并采用。此操作不解除旧采集记录的防重保护。另一台电脑上的旧记录未在本机代为修改。

## 范围与证据

不改计算模型、参数、仓归属、导出字段与文件完整性校验，不改采购上传和收货同步。应用0.49.5；0.49.4是独立删除性能分支，本版不包含其未合并工作。

测试使用隔离数据库、封闭假运输及拦截全部网络的独立 Edge 用户目录；不访问真实平台。Edge测试证明菜单收起后的恢复、恰好一次请求、隐藏/禁用/遮挡不提交、提交期间异常不冒充未提交。真实平台和出现问题的另一台电脑仍需现场验证。

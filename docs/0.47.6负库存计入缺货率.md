# 0.47.6：负库存按0计入门店缺货率

按用户确认的口径，门店可用库存为负数时，缺货率统计按0处理，正常纳入缺货；不再因此把整店和合计缺货率留空。原始库存值继续留存，用于原件追溯和明细导出，不改写翱象原表。

## 统计规则

- 有销基数：当前视角内月销大于0的门店商品数。
- 缺货数：上述有销商品中，门店可用库存小于或等于0的商品数。
- 缺货率：缺货数 / 有销基数；跨日期按店品日分子、分母分别加总后求比值。
- 门店停采/禁采（翱象补货状态）和实际供货仓禁用的商品，默认同时从有销基数与缺货数剔除。重叠命中只剔除一次；不受未参与供货的另一个仓状态影响。
- “备用”仍保留，未知状态不猜为禁用。淘汰品、考核品继续使用原先的虚拟分类剔除视角。若为核对原表取消状态剔除勾选，界面和导出会显示对应的包含状态商品视角。
- 月销为0的商品不进入基数，即使库存为负数也不计为有销缺货。月销缺失/非法/负数、有销商品库存缺失或非法，仍需要核对，不能当作0。

统计值对合法数值使用 `max(0, 可用库存)`，原始值保留在 `stock_raw`。缺货率页面、汇总、趋势、切面、只看缺货明细和Excel使用同一份重新生成的分析事实。Excel继续展示“原可用库存”，因此可以看到负值及对应的缺货标记。

## 已有日报如何更新

旧日报保存的是当时计算结果，升级不会直接覆盖原修订。若查询范围还包含按旧规则处理的负库存，页面会提示以下步骤：

1. 打开新版“门店缺货率 → 采集与快照”。
2. 选择标为“当前日报”的原采集作业，点击“用留存原件重算”。
3. 选择“原作业当时设置”，核对范围后执行。

重算只使用本板块留存的门店与仓原件，不连接平台、不重新导出、不改变原观测日期，也不更新补货业务的资料。全部完成后才发布新修订；取消、失败、原件缺失/变化或并发日报变更仍按原规则处理。原修订和原件继续保留。若查询覆盖多个日期，逐个当前日报处理；尚未重算的日期不会冒充新口径。

旧结果未重算前导出的Excel明确标注“含旧口径结果，需用留存原件重算”。没有负库存影响的旧范围，既有数值与新口径相同，无需仅为数值一致而重算。

## 改动范围

只调整独立门店缺货率模块的库存统计、口径提示与导出说明，统计口径标识由 `store-stockout-1` 升为 `store-stockout-2`。应用版本0.47.6；补货计算模型仍为0.3.4-rules，参数、预算、箱规、仓归属、普通订单删除和采购任务均未修改，数据库结构与存储格式不变。

具体源码提交、回归、隔离真实样本重算及EXE验证结果见本版交付报告。历史报告中的“库存=0”属于此前口径，不修改旧验收证据来冒充新结果。

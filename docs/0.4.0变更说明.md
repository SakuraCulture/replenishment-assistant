# 0.4.0 多店工作台

新增多文件/单文件多店归集，按门店编码和商品编码去重。相同记录去重；不同记录展示来源和字段差异，用户明确选择后才计算该店。部分文件读取失败时列明原因，其他有效文件可以继续。

四步界面：准备数据 → 门店与预算 → 并发进度 → 查看与导出。各店首次明确选择预算方式，限额空白不默认为0或不限；0预算仅保留需求。预算按门店记忆，商品资料记忆路径，必卖清单沿用原持久化方式。

默认2个独立子进程，可选1至4；单店计算顺序不变。正在计算时冻结本批次输入/配置；停止后不启动排队门店，已启动门店完成后保留结果。失败单独重试。

单店预算/参数改变只失效该店，共用数据或清单变化使相关结果失效。支持查看过期结果但禁止导出；未完成状态金额留空。支持合并工作簿及按店分别导出，并记录版本、参数、来源校验值。

模型核心、输入适配器、一箱例外、预算分配及默认业务配置均不修改。应用版本0.4.0，模型标识0.3.0-rules。没有统一日均、没有应用3.5+5或其他试验方案。

不包含跨店资金调拨、自动下单、联网共享或远程发布。并发验证使用真实鹿泉数据及明确标注的合成第二门店；不声称已在第二家真实门店实测。不声称已验证其他电脑或逐字节可复现构建。

# 0.47.5 全部初始化与勾选采购任务

本版用于清理开发测试资料和修复翱象批次范围。模型 0.3.4-rules、仓归属 0.5.2、参数默认值与存储格式保持原版本。

## 全部初始化

入口：**参数设置 → 全部初始化（开发测试）**。

确认页列明当前资料目录与完整备份位置。点“备份并全部初始化”后，程序通过原有安全退出流程等待作业结束，再将整个资料目录移动到同级的“初始化备份-时间-编号”目录，建立新的空白目录并退出。重新打开程序后使用程序初始默认。

包括本应用保存的订单、草稿、采集资料、作业记录和日志、缺货率数据、门店参数、必卖清单、应用浏览器连接配置、自动作业配置、平台关联和采购意图。外部输入/导出文件、程序目录及旧交付包不在资料目录内的，不受影响。浏览器自身的登录资料和平台采购单不删除。

**平台已创建的采购单仍然存在。** 本机平台关联随旧资料移入备份，初始化后不能依赖旧关联防止重复采购；旧订单应先在平台核实，不要当新任务重新上传。此前“初始化保留参数与平台关联”的备选范围，已按“全部初始化”的要求取消。

同目录其他实例、旧版补货助手窗口或数据库写入仍未退出时，不执行初始化。请正常关闭其他补货助手窗口，再操作；不强杀正在提交的任务。若提示“正在安全结束作业”，本次没有初始化，待任务安全结束及采集窗口关闭后重新点击。

备份始终保留，初始化不等于释放这些资料占用的磁盘空间。初始化失败或进程在目录切换中断时，下次启动会先检查记录；未完成切换自动恢复原目录。遇到原、新目录同时存在非空数据时停止启动并保留两者，不覆盖。

恢复备份：关闭所有补货助手，将当前新资料目录另存，把完整备份目录恢复为确认页列出的原资料目录，然后打开原兼容版本。不要只恢复某张表或单独覆盖数据库文件。

## 仅执行勾选项

在“翱象批次作业”左侧勾选未处理、失败或待核项，点 **仅执行勾选项**。按批次原顺序处理所选项；其他项保留。停止后“继续上次勾选范围”仍只处理该范围；处理完后不会自行启动剩余订单。

所选采购预览成功后，可直接点“确认上传勾选的采购预览”。仍需确认上传，准备预览不自动上传。勾选已就绪预览后再点“仅执行勾选项”会提示使用上传入口，不会重新准备同一单。

“继续整批未完任务”用于尚未设置勾选范围的批次；“重跑全部失败项”明确以失败项为范围。已有平台采购身份继续使用原身份核对，不新建身份或清除上传标志。

## 已删订单与本地任务删除

订单入队、准备执行以及首次上传前复核本机原订单；已删除或该仓单已在回收站时停止新采购。仓单回收站检查按仓区分，不影响同父单另一仓。

刷新批次时清理已删订单的纯本地准备残留；保留带采购身份、平台回执等证据的记录，并标记原订单已删除。**删除勾选本地任务**仅删除选中的、未产生平台采购身份的本地批次项，不删除业务订单。已上传或结果不明的记录不能通过此按钮抹去，应核对原任务或使用明确的全量初始化。

订单标准永久删除原本已同步清理关联批次。本次修的是旧残留、回收站可见性及过期订单快照重新入队/执行的入口；没有修改正常订单删除的范围、事务原子性、并发检查或完整性校验。

## 证据与限制

验收使用隔离目录和合成平台响应，不创建、取消或删除真实平台订单，也不清空用户当前资料。发行报告记录源码/EXE通过项及未通过的首次验证，不将单元测试替代平台实测。

本次没有重测大历史库删除性能；不能据此宣称37秒删除耗时有所下降。旧版回调告警未在本次修复范围。

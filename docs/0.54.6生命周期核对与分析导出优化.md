# 生命周期核对与经营分析导出优化

保持数量、金额、商品/门店顺序、原有校验、默认并发和提交规则。

生命周期核对：商品行的明确匹配、门店/仓/修订检查、重复冲突和取消检查保持。补货单号只解析一次，数据库版本在读边界观察；若期间有提交，重新通过原解析器核对已用单号。每个精确绑定首次验证，冻结每张整单方案前再次验证，最终保存事务仍执行原有来源、修订、上游、摘要和CAS校验。无新增持久缓存或长读事务，不因其他任务的无关写入直接拒绝。

分析模板：固定字体、填充、对齐和数字格式组合只在当前工作表所属工作簿内创建、登记一次，已建立的组合只读复用。缓存键包含样式名、水平对齐、换行和数字格式；文本SKU和名称仍强制文本，公式和公式缓存处理不变。不同导出之间不共享工作簿样式ID。

导出核验：每次导出先执行原完整快照校验。仅同一次操作内，主数据库文件身份、数据版本、物理文件状态、查询、头身份和快照号均未变化时，才允许复用这次核验；独立翱象组件的采购关联状态及旧冻结依据文件仍重新读取、核验。不确定、数据变化、文件替换或上下文变化则退回原完整校验，保留原决定与异常。历史截至查询不因较新的提交被新增拦截。缺少证明条件不作为新门禁。

原完整校验函数没有改为轻量函数；关联缺货率的独立核验、取消检查、写入私有临时文件、最终核对后发布等边界保留。只读连接不保持跨Excel写入的读事务，操作结束即关闭；证明不落库、不跨导出复用。

不改变补货计算、预算、箱规向上规整、库存不足分完剩余量、主从仓、真实平台请求、订单数据和默认并发。无需业务新增维护步骤。独立包和实测以本版交付报告为准，保留旧交付与验收证据，不自动替换当前软件或执行真实业务。

# 完整门店参数与批量导入

应用0.26.0，基于0.25.0的2721aa34。模型公式及默认配置保持，模型版本仍为0.3.3-rules。新增可选分类超参，不填写时计算结果保持原口径。

## 使用

参数设置 → 批量导入门店参数 → 下载完整模板。仅门店编码必填，其余按需填写，也可以删除不修改的列、改变列顺序。完整模板包含门店预算/主从仓、全部已有可编辑模型超参、快销/日百权重、分类映射、分仓周期，以及新增分类超参。先核对差异，再选择仅保存默认、仅用于本次或同时应用保存。

门店默认中的“完整参数 → 分类超参”可分别启用快销/日百的常规资格周转阈值、低月销基本售价门槛、库存目标分位概率。未勾选沿用门店通用值；两仓共用一套分类参数，无分类跟随快销，仓周期各自保留。生效核对明确展示覆盖关系，源表注入记录按字段表单展示。

Excel列名为 `分类参数/快销/常规资格周转阈值`、`分类参数/快销/低月销基本售价门槛`、`分类参数/快销/库存目标分位概率`；日百同理。概率使用0.90/0.95等小数，允许0.50～0.99。空白保持现值；填“沿用门店”清除该项分类覆盖。权重w3仍自动为1-w1-w2，不重复维护。默认导出会携带已设置的分类值，可完整回导。

周期在各仓列维护，不另开放重复的通用周期输入；极端缺货边界固定30天，不借批量导入更改模型规则。原表的二类医疗资质、聚水潭门店名称作为来源信息留存，不虚构新的资质拦截或名称关联规则。

## 数据与计算边界

可选 `profile_parameters` 是配置schema2新增字段。schema1历史配置仍可读取，未设置分类值时保持原门店参数。分类权重先在仓路由后绑定，再按同一分类方案绑定AI/AJ及目标概率；核心仍调用同一个model.calculate，不复制模型。概率通过每分类缓存的Rules传入，启用时结果行记录 `_effective_probability`，可结合结果配置和原表来源追溯。原model/一箱例外/预算算法及默认配置不修改。

这次现场参数经用户确认，将原表Z=1.28/1.65对应为90%/95%，不是使用正态CDF算出更精细的小数；原Z值留档。分类阈值接入的是模型已有AI/AJ资格条件，不是增加盘点自动化。新参数允许改变本次重算结果；旧参数的严格对照要求零差异。

保存默认不会改变当前已计算草稿、历史签发及已导出文件。需新建/重新导入作业以自动带入，或在界面明确应用到当前作业后重算。

## 兼容与回退

使用新分类配置必须运行0.26.0或更新程序；0.25.0及以前不能读取新增配置字段。旧包保留，回退时应使用注入前的配置/数据库备份，不能用旧程序继续写入新配置。历史记录不迁移、不回写。现场Excel、门店数据及备份不纳入Git、不推云。

# 补货助手 0.13.0：操作范围、保存边界与独立导出

## 使用方式

完整保留程序目录，运行其中的“补货助手.exe”。旧0.12.0包保留；本次不合并、不推送，不迁移日常数据库。

- 历史页：**勾选用于批量操作；行内“查看单据”用于查看一个仓单**。高亮行不参与批量删除或导出。
- 正常归档显示“移入回收站”；回收站显示独立“恢复归档”。作用于勾选仓单的全部修订，另一仓、原签发数据和回传保留。整批状态冲突会回滚。
- 三个常用入口保持独立：导出完整计算表、下载商品资料原表、导出签发建议。加工资料核对表另设次级入口。原表缺失不能用加工表代替。
- 工作页“制作加盟商确认单”先选择门店/仓，再核对**完整草稿保存范围、完整门店签发范围、实际导出仓范围**。有变化时“确认归档并导出”，相同时“导出已签发版本”。自动归档规则不变。
- “仅确认归档”也明确选店；“安排新品”在汇总页要求选店，在单店详情页明确店名。新品计算和预算分配不变。
- 门店表可分别“全选当前筛选”“全选本批可计算”，显示隐藏的已选门店数。参数状态独立显示；“编辑参数”和“查看生效参数”分开。
- 门店参数窗口只负责本次应用/保存门店默认。公共方案另由“管理参数方案”维护，保存或停用立即生效，不应用门店；关闭窗口不撤回已经保存的方案。
- 单据内“导入本仓单回传”限制确切订单、仓和修订；多订单文件请用历史页“批量导入加盟商回传”。回传数量始终独立保存。
- 任务按钮按阶段明确“取消准备”“正在提交，暂不能取消”“停止剩余导出”。提交后停止导出不会删除已归档单据，已完成文件保留，可从历史按原修订重试。

## 业务与兼容边界

应用版本0.13.0；模型仍0.3.3-rules；仓归属0.5.0；作业/参数schema1、物理存储2不变。计算、中间值、预算、路由、新品数量和导出生成实现不变；不引入8.5天目标或其它未批准模型方案。

唯一持久行为扩展是用户明确勾选后的批量回收站操作：复用原可见性表和事件格式，不删除/重写签发快照、原文件、回传、每日草稿。单条兼容函数委托同一实现。首次写入前保留原备份；失败回滚不代表备份文件未生成。

参数核对表沿用既有8位小数编辑控件；本次没有调整其原精度或预测参数。未编辑判定使用表单已渲染值，避免把既有数值显示精度误判成用户编辑。逐店应用依旧是完整表单应用，不新增字段补丁语义。

历史原件缺失仍不能还原；原表保留所有sheet及原文件字节。加工核对表继续明确标注加工。跨页勾选保留，改变历史查询条件清空勾选；门店筛选保留已有选择并展示隐藏数。

公共方案停用后仍没有恢复入口，本轮确认页明确说明；内置标准版不允许停用。未扩展实际下单/收货归档关联。

未测速度提升，本轮不宣称性能收益；额外的范围确认属于明确操作边界，完整归档导出仍有原有读写成本。

# 0.47.7：门店缺货率多维切面与导出

本版仅扩展独立“门店缺货率”板块的分析视角、筛选和Excel报表。用户确认的结构是：每套维度组合一张工作表，每行是一组完整数据；一次可以选择多套组合。原有负库存、停采/禁用剔除、主从仓及补货计算规则保持。

## 操作方法

1. 进入“门店缺货率”，选择观测日期和剔除视角。
2. 点“多维筛选…”：左侧选维度，右侧按编码或名称搜索后勾选。可跨页保留选择；“只看本维度已勾选项”可查找或取消已有选择。点“应用筛选”更新总览、趋势、切面和明细。
3. 在“切面分析 → 管理 / 自定义组合”中新增组合，命名并勾选维度。通过向上、向下或拖动调整列顺序。点“保存并查看选中组合”。以后可用“已保存组合”直接切换。
4. 点“导出本视角Excel”，勾选要导出的多套组合，按需附带商品明细，再选择新的保存文件名。

每套组合支持1至12个不同维度：门店、供货来源、必采属性、供货仓、商品类目、仓库上游供货商、观测日期、仓商品状态、翱象补货状态、在途情况、标签依据、商品。门店和商品同时提供编码、名称；编码是分组和筛选依据，同名不同编码不会合并。

例如“门店＋供货仓＋上游供货商＋商品类目＋必采属性”，每行依次列出门店编码、门店名称、供货仓、仓库上游供货商、类目、必采属性，再列有销基数、缺货数、缺货率、待核及剔除数量。添加商品维度后，同一行追加商品编码、名称，不拆成多个维度各占一行。

快捷两维入口仍保留；更改快捷选择会切换回相应的两维组合。当前实际采用的全部维度在“当前：…”明确列出。

## 筛选和报表口径

- 同一维度多选为“或”，不同维度之间为“且”。没有勾选的维度不限。
- 候选项按当前日期与其他已选维度查询；搜索不会清掉已选项。门店、商品支持编码或名称搜索，筛选保存精确编码。
- 筛选作用于页面总计、每日趋势、切面、商品明细和本次导出的所有组合。日期维度筛选也缩小日报覆盖和快照依据。
- Excel每张数据表有真实筛选按钮、冻结表头，百分比为可计算的数字。各切面是相同数据的不同分组，不应跨表累加；期间率继续采用分子、分母分别加总后的比值。
- 工作簿另附口径、覆盖、快照依据、总体、标签剔除对照和趋势。标签剔除对照表按行显示不同标签视角，保留当前维度筛选和状态剔除开关。
- 明细导出包含剔除标记及原始库存，保留原有核对方式。“只看缺货”等明细页开关仅改变页面明细浏览，不改变当前视角分母或导出筛选；要缩小导出范围使用“多维筛选”。

“供货仓”中地采商品统一显示为“地采”，覆盖旧日报里的“不适用”。这只是读取和展示口径统一，不改写旧快照，也不把商品归属到未选仓。仓库上游供货商对地采继续明确为“不适用（地采）”，不猜地采供应商。

## 容量与隔离

- 页面每页最多200组/条，显示总数；导出流式覆盖全部分组，不受200行页面上限影响。每个切面仅执行一次分组查询，避免按页反复汇总和OFFSET扫描。
- 最多保存32套组合，每套最多12维；每个筛选维度最多勾选1000项。日期范围继续最多366天。筛选候选分页查询，不一次加载所有商品。
- 工作表超过100万数据行时自动续表，口径页记录续表关系；不截断记录。组合名称中的Excel保留字符会转为下划线，重名加序号。
- 组合设置仅保存到本分析目录的`views.json`；不进入分析时不加载它。保存有并发版本检查，不覆盖另一窗口的新组合。
- 只使用既有独立分析快照；不自动更新补货资料、不发起平台采集。地采显示变化不需要重算。0.47.6之前负库存旧日报的离线重算提示继续保留。
- 导出仍使用新文件名、临时文件完成后发布。取消和失败清理本次临时文件，不覆盖已有报表。

应用0.47.7，模型0.3.4-rules、仓归属0.5.2、参数3、作业1、存储格式2、分析库结构1及统计口径store-stockout-2均不变。实际验证、构建提交和限制见[交付报告](../releases/0.47.7/rc1/交付报告.md)。

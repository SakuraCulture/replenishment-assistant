# 付款认单只使用商品编码

自 0.50.1 rc3 起，导入聚水潭财务／付款单时，只用“商品编码”核对商品。辅助码和原签发条码不参与匹配、映射或冲突拦截，不能把付款表的商品编码替换为另一个编码。

- 付款表原有辅助码列可以保留；缺少该列或有重名辅助码列，不影响认单。原始文件继续留存，不需要手工清理该列。
- 商品编码存在于所选仓单，按该编码核对数量与金额；辅助码指向什么商品都不影响认单。
- 商品编码不在所选仓单中，按清单外商品待核，不能凭辅助码／条码把它认成清单内商品。
- 商品编码明确属于另一供货仓时，仍提示核对目标仓单。

门店、供货仓、签发修订、内部订单号原关联、防止重复绑定及数量金额差异核对继续保留。此改动不追溯改写已经保存的历史付款单，不改变计算模型、预算、箱规或商品归属。

升级后重新读取原付款文件，再进行自动识别或手动选择目标签发单。此前“商品编码与辅助码指向不同商品”“辅助码对应多个商品”的认单拦截不再产生；其他独立的归属冲突仍按具体提示处理。

# 0.31.0 聚水潭商品资料同步试用

这是本地候选包。保留原来的0.30.0，解压完整文件夹后启动“补货助手.exe”，不要单独移动EXE。本版未合并或推送。

## 第一次连接

1. 进入“补货出单 → 准备数据 → 分仓商品资料 → 聚水潭连接设置 / 刷新仓资料”。
2. 选择山东仓或河北仓，选择这个账号已有的专用浏览器配置目录（Default或Profile目录）。这里不能选翱象使用的正常Edge目录，也不能把同一个浏览器的两个Profile当成两个独立仓账号。
3. 点击“核验所选浏览器”；需要登录时点“打开登录页”，正常登录后再核验。出现允许远程调试连接提示时需允许。程序不保存密码，也不绕过验证码或登录校验。
4. 核对公司及商品数，确认这个账号的商品资料和可用库存属于所选物理仓，勾选确认，再保存。山东、河北各自保存，后续重复使用。暂时只用一个仓时只配置一个即可。

本机已按用户确认保存：团团甄选供应链（临沂）有限公司对应山东仓，优团河北石家庄仓对应河北仓。换电脑需重新选择专用浏览器并登录，不搬运Cookie。软件保存账号与浏览器的绑定，复用登录态；不保存密码，不承诺登录失效后无人值守补登。

## 日常刷新

点“刷新所选仓资料”，或“刷新所有已启用仓资料”。程序依次连接、查询全部状态商品、提交平台导出、下载原任务文件、校验、留存原表并采用。成功后资料跨批次复用；当前已算结果需要重新检查，原签发与历史单不变。

一仓失败不覆盖其旧资料，也不撤回另一仓已采用结果。停止后可继续原记录，或仅继续上方所选仓；已成功的仓跳过。平台受理不明时会阻止重发，不会猜最近的一份下载。

## 更新聚水潭分配库存

更新默认资料不会直接重置已分配库存。需要生成聚水潭订单时，在原分配页点击“从聚水潭刷新并用于本次分配”；随后按原流程重新预览、生成。查询期间发生锁单或库存分配变化时，这次文件会保留但拒绝采用，应重新获取。

# 0.42.0 参数批量快捷设置

本轮仅收敛常用设置与模板填写，不调整计算模型、预算分配、箱规规则、全局分类映射及历史快照。基线0.41.2的da3546a，独立分支feat/parameter-quick-actions-0.42.0；不推送、不合并，旧包保留。

## 业务操作

### 同一设置给多家门店

参数设置勾选门店，点顶部“批量设置开关 / 预算 / 供货仓”。一箱例外、极端缺货自动恢复、新品铺设可选择开启或关闭，初始都是“保持各店原值”。预算可选不限预算或限定预算，限定时输入统一金额，0元表示不安排。供货可选山东单仓、河北单仓、双仓及主仓方向；各仓周期不随供货选择改变。

核对逐店差异后保存以后默认，不改变当前作业。第二步“门店与参数”提供同名入口，仅应用本次，变化门店结果失效并需要重算。未选门店、未选字段均保持原值；开启新品仍需要选品。

### 直接应用已有方案

参数设置顶部“应用参数方案”保存以后默认；计算准备“应用参数方案到本次”用于当前选中的门店。先显示分仓周期、分类权重与库存目标分位概率及策略摘要，再核对逐店完整差异。计算准备另有“同时保存为这些门店以后使用的默认方案”，默认不勾选。

预算、供货仓及分类映射分别保留当前/长期配置原值，不将当前预算顺带写入长期默认。保留映射与目标方案不兼容时整批拒绝，不自动改映射。当前设置或共享方案在预览后变化时要求重新核对。保存失败不采用到当前作业；只改方案名字且有效配置一致时不废弃原计算结果。保存的默认方案仍按原机制跟随后续方案版本；当前采用的是冻结参数。

### 各店不同数值时再用Excel

分组模板表头及数据行位置保持：门店编码必填；分仓周期另填属仓，分类参数另填分类组。必填表头用黄色字，单元格批注及输入提示说明规则。预算方式、仓、策略和分类组提供下拉。自定义分类组允许填写，但必须存在于门店方案中。

- 新版V3：空白、缺列、缺行不修改；参数填写“系统默认”才恢复，分类专用参数恢复后沿用门店通用值。
- 旧V2：继续数值参数空白恢复默认的原规则；导入预览明确版本，不暗中改旧表含义。
- 旧混合模板：继续空白保持的原规则，作为兼容入口，本轮不重设计旧混合表。
- 只填预算金额自动采用限定预算；0元就是0元，不是缺失。
- 限定预算的金额空白：保留已有金额；没有有效金额则提示门店、来源行与填写要求，不补0。
- 不限预算或未指定时填写金额，明确报错，不静默丢掉金额。
- 下拉不替代软件校验，粘贴非法值仍在导入阶段拦截。

## 代码与边界

parameter_quick_ui复用store_parameter_ui的预览、并发检查、整批保存与结果失效。parameter_preset_ui提供方案摘要和当前快照核对，默认绑定复用parameter_presets.assign，不另建存储。parameter_template_help只增加模板填写辅助，不改变表头解析。store_parameter_import只补充限定预算缺金额的错误提示，不改变原可接受值。

没有重做整个参数页面或新建方案编辑器；全局映射、旧模板、资质/拒收及高级参数入口保留。本轮未测真实AI客户端与平台，不更改其权限。日常用户配置没有被测试修改。
